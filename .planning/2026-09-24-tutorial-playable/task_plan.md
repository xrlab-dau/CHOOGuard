## 착수 시점의 사실 (2026-09-24 실측)

직전 작업에서 PlayMode 61/61 이 통과한 상태였다. 그런데 씬을 실제로 켜면 다음이 성립하지 않았다.

- **판정을 고를 수 없다.** `FireExtinguisherSliceBuilder` 가 월드 상태를 읽어 정답을 `session.PendingVerdict` 에 미리 넣고 있었다. 플레이어가 고를 것이 없고 `MisjudgementCount` 는 영원히 0 이다.
- **점검표가 보이지 않는다.** `InspectionTagPrefab` 이 null 이라 `TutorialSession` 이 렌더러 없는 빈 `GameObject` 를 생성했다.
- **역할 경계를 어길 수 없다.** `TryFieldRepair()` 호출처가 저장소 전체에 0 건. 채점 항목인 `RoleBoundaryViolations` 가 구조적으로 0 고정이다.
- **튜토리얼에 도달하지 못한다.** `SceneManager.LoadScene` 호출이 0 건. 빌드 설정에 두 씬이 등록돼 있어도 Bootstrap 에 머문다.

61 개 시험 중 어느 것도 이 넷을 잡지 못했다. 시험이 세션 API 를 직접 호출해 사람이 지나는 경로를 건너뛰었기 때문이다.

## 규율 (어기지 않는다)

- **시험이 실제 경로를 지나게 한다.** 공개 메서드만 부르는 시험은 게이트(`IsPaused`)를 지나지 않는다. 키 매핑 계층을 분리해 같은 경로를 태운다.
- **생성기와 씬은 한 벌이다.** 코드를 고치면 씬을 다시 만들고, 직렬화된 값을 눈으로 확인한다.
- **되돌릴 수 없는 것을 되돌린 척하지 않는다.** 되감기는 단계가 남긴 월드 상태까지 되돌리거나, 되돌릴 수 없으면 거부한다.
- **기존 시험을 깨뜨리면 그 시험이 옳다고 먼저 가정한다.** 부트 시험과 입력 라우터 시험이 각각 한 번씩 깨졌고 둘 다 내 설계 오류였다.
