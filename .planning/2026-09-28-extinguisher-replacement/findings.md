## 대기 — 링크를 올린 재측정 (Unity 실행 전에는 값을 적지 않는다)

프로브는 이제 세션 시작 상태의 에스컬레이터·엘리베이터 링크를 올린 뒤 잰다. 멈춘 벨트·막힌 진입 같은 실행 중 변화는
모델링하지 않는다. 출력은 `artifacts/extinguisher-probe/measure-<UTC>.json`(git 무시)이며
`measure-a.json` 을 덮어쓰지 않는다. 스키마가 그대로라 JSON 만으로는 링크 유무를 구분할 수 없다 —
경로와 콘솔 `CG_FE_PROBE … links=유효/시도` 로 구분한다.

실행해서 알아낼 것(값은 실행 결과와 출력 파일 이름을 함께 적는다):

1. `links=` 의 유효/시도가 같은가.
2. FE-005 와 이웃 5대의 판정(REACHABLE / PARTIAL_PATH), `reachableFrom`.
3. 링크를 올린 성분 구조(`CG_FE_COMPONENTS`) — 갈라짐이 남는가, 남는다면 성분 1 과 3 의 분리가 의도(타는 곳 게이트의 물리적 차단)인가 결함인가.
4. FE-001·002·007·008 이 링크를 올려도 혼자인가.
5. 사람의 눈: FE-005 가 벽에 박히지 않았는가 · 판독면이 읽히는가 · 앞에 설 공간이 있는가(배치모드 측정은 답하지 못한다).
6. 승객 110명(`CrowdDirector`)이 이 성분 구조에서 어떻게 움직이는지 — 갈라져 있다면 소화기만의 문제가 아니다.
