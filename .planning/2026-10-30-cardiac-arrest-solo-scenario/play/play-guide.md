# 심정지 연습 직접 플레이 안내 (2026-10-31)

브랜치 `feat/cardiac-arrest-drill` 작업 트리(미커밋) 기준. Meshy 부품(열린 본체·패드·충격 버튼)이 들어간 상태.

## 1. 실행

### 1-a. 타이틀의 튜토리얼 목록에서 (2026-10-31부터, 환경변수 없이)
1. Unity 에디터에서 Bootstrap 씬을 열고 재생(또는 빌드 실행).
2. 타이틀 → **플레이 시작 → 튜토리얼 고르기 → 심정지 환자 대응**. 보존 근무(EmergencySession)로 역 씬이 뜨고, 30초 뒤 2층 맞이방(대합실·본관)에서 심정지 환자 한 건만 생깁니다. JEV 키가 없어도 됩니다.
3. 아래 2·3절대로 대응합니다. 환자에 E(상태 확인)를 하면 길 안내(지도 M·나침반·바닥 점선)가 AED 보관함을 가리키고, AED를 들면 다시 환자를 가리킵니다.

### 1-b. 에디터 메뉴에서 (환경변수로 세부 설정)

1. 같은 프로젝트에 배치 Unity(시험·촬영)가 돌고 있지 않은지 확인한다. 에디터는 한 번에 하나만 뜬다.
2. `play-cardiac-drill.cmd` 를 더블클릭한다. 연습 설정(심정지 즉시형, 2층 대합실·본관, 손 떼기)은 환경변수로 들어가므로 Hub 로 열면 적용되지 않는다.
3. 에디터가 뜨면 메뉴 **ChooGuard > Practice > 심정지 환자 한 건**. 타이틀 씬이 열리고 재생이 시작된다.
4. 타이틀에서 **플레이 시작 → 랜덤 비상상황 대응**. 근무가 준비되면 30초쯤 뒤 2층 대합실 어딘가에서 승객 한 명이 쓰러진다(이 건만 일어난다).
5. 손 떼기 모드라 역무원이 직접 알아내야 한다: 주변 승객이 다가와 알려 주거나(약 20초 뒤), 직접 보고 찾는다.

## 2. 조작

| 키 | 동작 |
|---|---|
| W A S D, Shift | 걷기, 달리기(AED·소화기 들면 달리기 불가) |
| 마우스 | 시선. 우클릭 길게: 자세히 보기 |
| E | 조준한 대상에 동작(화면 가운데 "E · …" 문구) |
| R | 두 번째 동작("R · …"): 환자 가슴압박 시작/멈춤, 바닥의 AED 다시 들기 |
| Q (누른 채) | 무전 바퀴: 역무실 보고(환자 발생 → 119 요청) |
| G | 손에 든 것 내려놓기(AED 바닥에, 패드는 뚜껑으로) |
| Tab / M | 근무판 / 지도 |
| Esc | 일시정지 |

## 3. 심정지 대응 순서(기기 음성이 지시)

1. 환자에게 E **상태 확인** → Q 로 **역무실 보고**(구급 요청) → 2층 본관 철도경찰 앞 **AED 보관함**에서 E **AED 꺼내기**(약 74 m).
2. 환자 곁에서 환자에 E **AED 곁에 두기**(또는 G).
3. AED 에 E **뚜껑 열기** → 전원이 켜지고 음성이 시작된다.
4. 뚜껑 안의 **패드에 E**(집기) → **환자에 E**(붙이기, 오른쪽 빗장뼈 아래) → 둘째 패드도 같은 순서(왼쪽 옆구리).
5. 기기가 "모두 환자에게서 물러나십시오" → **환자에 E "물러나세요!" 외치기**(가슴압박 중이었으면 멈춘다) → 분석 5초(손 대면 중단).
6. "제세동이 필요합니다" → 충전 3초 → 버튼이 빨갛게 깜빡이면 **AED 에 E 충격 버튼 누르기**.
7. 충격을 가했거나 "전기충격이 필요없습니다" → **환자에 R 가슴압박 시작**. 120초 뒤 기기가 다시 물러나라 하면 5부터 반복.
8. 구급대가 도착해 처치하면 기기는 조용해진다. 구급대장에게 E 로 **현장 인계**.

## 4. 끝과 기록

- 구급대 처치 또는 15분(`CG_PRACTICE_RECORD_AFTER=900`)이 지나면 기록이 `drills/drill-<일시>.json` 으로 저장된다. 메뉴 **ChooGuard > Practice**… 에서 `Report` 는 배치 전용이고, 파일을 직접 열면 된다(aedAt·aedPadsAt·aedClearCalls·aedShocks·compressionSeconds·handover·timeline).
- 재생을 멈추면 끝. 씬은 저장하지 말 것(연습은 씬을 바꾸지 않는다).

## 5. 알려진 한계

- 패드 붙이는 자리는 휴머노이드 뼈 기준이라 앉은 채 쓰러진 환자에게는 몸통 앞에 붙는다.
- 가슴압박 자세 애니메이션은 없다(손 칸과 기록으로만 보인다).
- Meshy 열린 본체는 닫힌 본체와 다른 모델이라 켜는 순간 형태가 바뀐다(뚜껑 여는 동작 없음).
