# FPS Reality Benchmark Plan

## Goal
Build a primary-source-grounded benchmark of six FPS or first-person games, translate their reality-abstraction patterns into safe KORAIL station-staff mechanics, and emit only the requested evidence library plus source graph.

## Scope
- Research only; no Unity, `Assets/`, canonical product docs, or controller publication.
- Six games with deep, bounded evidence: PUBG, Sudden Attack, Ready or Not, Alien: Isolation, Half-Life: Alyx, Firefighting Simulator.
- For each proposed mechanic: real concept, abstraction, input, constraint, observable feedback, success, failure, recovery, source locator, playable-evidence boundary.
- Separate combat-only mechanics from station-staff-safe transfers.

## Phases
1. [complete] Inspect existing scope/evidence and gather official primary sources.
2. [complete] Extract bounded mechanic evidence and capture source records.
3. [complete] Synthesize migration matrix, recurring patterns, accessibility/agency findings, and anti-patterns.
4. [complete] Validate JSON, source references, file boundaries, and deliver graph to root.

## Decisions
- Developer pages, official manuals/help pages, official patch notes and developer conference talks are eligible primary sources.
- Marketing descriptions establish declared features; exact input/feedback causality requires manuals, patch notes, or inspected official footage with a timestamp/frame note.
- Lack of independently running each game is explicit; footage/manual evidence is a design benchmark, not product acceptance.
