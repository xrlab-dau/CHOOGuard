# Findings: navmesh 가 잘게 조각나 아무 데도 못 갔다

## 1. 첫 베이크는 통째로 쓸 수 없었다

경로 질의가 **모든 목적지에 대해** `partial_path_target_unreachable` 을 돌려줬다.
20 개 후보 전부였다. 목적지가 나쁜 줄 알았는데 아니었다.

실패 사유에 **폴리곤 수를 실어** 다시 보니 답이 나왔다.

```
22m  90도 · partial_path_target_unreachable(polys=1)
22m 120도 · partial_path_target_unreachable(polys=1)
22m 270도 · partial_path_target_unreachable(polys=4)
```

`polys=1` — 시작 지점이 **폴리곤 한 개짜리 섬** 위에 있었다. 어디로도 갈 수 없는 게 당연하다.

### 원인

785㎡ 대합실에 폴리곤이 **6,328 개** 나왔다. 0.12㎡ 에 하나 꼴이다.
바닥 메시가 잘게 나뉘어 있는데 격자(`cs=0.2`, `ch=0.05`)가 촘촘해서 그 조각을 그대로 옮겨 적었고,
`walkableClimb=0.35` 로는 조각 사이 미세한 단차를 넘지 못해 서로 이어지지 않았다.

천장도 문제였다. 대역을 시작점 ±(3,5)m 로 잡아 천장이 들어왔고, **위를 향한 천장 면이 또 하나의
보행층**으로 잡혔다.

### 고친 것

| | 전 | 후 |
|---|---|---|
| 대역 | 아래 3m · 위 5m | 아래 1.5m · 위 2.5m (천장 제외) |
| 격자 `cs`/`ch` | 0.2 / 0.05 | **0.3 / 0.2** |
| 단차 `walkableClimb` | 0.35 | **0.5** |
| 최소 영역 / 병합 | 2 / 4 | **8 / 20** |
| 폴리곤 | 6,328 | **2,572** |
| 경로 | 전부 실패 | **24.2m · 꺾임 3 개** |

## 2. 실패 사유에 수치를 싣는 것이 결정적이었다

`partial_path_target_unreachable` 만 봤으면 "목적지가 나쁘다" 로 잘못 짚고 목적지 후보를 늘렸을 것이다.
`polys=1` 하나가 원인을 정확히 가리켰다. **이유 문자열은 분류가 아니라 증거를 담아야 한다.**

## 3. 기존 코드는 왜 못 썼나

- `MvpTeamNavigation`(48줄) — DotRecast 질의 래퍼. 구조는 쓸 만하나 `y≈5.05` 층을 하드코딩하고
  `ChooGuard.App.Mvp` 네임스페이스라 FPS 가 RTS 계층에 의존하게 된다.
- `MvpTeamNavigationBuilder`(55줄) — `MvpStationView.FloorRoots[1]` 과 메시 이름
  (`공개 외곽 기반 바닥`·`국소 기준 계산 영역`), 높이 대역 5.35~6.8 에 묶여 있고
  바닥 메시가 정확히 2 개가 아니면 던진다.

**DotRecast 자체는 재사용하고** 베이크·질의만 FPS 쪽에 새로 뒀다. 길찾기를 직접 구현하지 않는다.

## 4. 읽을 수 없는 메시 12 개

`isReadable=false` 라 navmesh 에서 빠졌다. **그 구조물은 승객에게 장애물이 되지 않는다.**
조용히 넘기지 않고 경고로 남겼다. 임포트 설정의 Read/Write 를 켜야 반영된다.

## 5. 결과

| 항목 | 값 |
|---|---|
| navmesh 폴리곤 | 2,572 |
| 승객 이동 | 25.1m (직선 23.4m) |
| 경과 | 20.0 초 |
| 상태 | `ARRIVED` |

프레임으로 확인했다 — 갈색 캡슐이 대합실을 가로질러 걷는다.

## 6. 이 조각이 하지 않은 것

- **유도.** 플레이어가 가리켜 보내는 것은 다음 조각이다.
- **못 들음·동행 대기.** 상태는 넷뿐이고 그중 사회적 상태는 없다.
- **몸.** 캡슐이다. 애니메이션도 얼굴도 없다.
- **여럿.** 한 명이다. 서로 피하는 것도, 군중도 없다.
- **콜라이더.** 일부러 뺐다. 이 조각의 목적은 "걷는가" 이지 밀치기가 아니다.
  그래서 `STUCK` 은 아직 실제로 발생시켜 본 적이 없다 — 코드 경로만 있다.
