# CS-EXEC.01.01 — 실제 부산역↔도시철도 연결 근거로 재설계

최신 사용자 교정: 현재 통로는 맵을 억지로 끼워 맞춘 결과. 실제 부산역과 도시철도 연결 자료를 확인하고 제작해야 한다. 이를 우선한다.

- COMPLETE_한정 실제 연결 조사: 부산교통공사 역 안내도·출구별 목적지·공식 접근 안내와 날짜/위치가 확인되는 사진·연속 보행영상으로 철도역 문→광장/지하구간→도시철도 출입구→대합실→승강장 동선을 확인한다.
- ACTIVE 원본 모델 검증: 사용자 자료의 제작 시점·공간 범위·실제 부산역과 일치/불일치 부분을 분리한다. 원본 파일이라고 현장 동선 증거로 간주하지 않는다.
- PENDING 근거 지도: 각 구간에 출처·좌표·연결 방식·층·확실성·부족한 정보를 붙이고 Jev와 root가 대조한다. 추정 레벨/임의 직선·벽 절단으로 연속성만 만드는 방법은 채택하지 않는다.
- PENDING 구현: 확인된 경로를 바탕으로 Astra low가 복원. 경로 판정 전 기존 추정 통로 추가 구현·완성 주장은 중단한다.

기술적 이력: Metro capsule 왕복 PASS는 임의 연결 프로토타입의 동작 증거일 뿐 실제 부산역 연결 수용이 아니다. KTX2호차 local boarding/return, 원본 텍스처/축·깊이/지붕 복구는 별도 기술 결과로 보존. 현재 NOT_A.
현재 사용자가 열린 Editor를 조작 중이므로 카메라/플레이어/씬/Play모드 변경하지 않는다. 컴퓨터use금지. 싱글플레이 코레일역무원 FPS, 별도 복기/퀴즈 제외, 한 스토리 유지.
