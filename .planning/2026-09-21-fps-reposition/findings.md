# Findings

- 공식 부산역 원본 8구역·51메시·299텍스처가 현재 MvpWorkspace에 통합돼 있다. 정확히 식별한 3D 역명 문자만 제거했다.
- 원본 대합실은 대부분 빈 내부이며 기존 0/5/10m 층을 뒷받침하지 않는다. 실제 문 문턱0/7m, 계단0→7m가 확인됐다. FPS 실내 이동에 기존 임의 바닥을 정확한 현장으로 재사용하면 안 된다.
- KTX 사용자 제공 ZIP은 기존 참고 평면을 제거한 64.916×2.873×4.070m 차량 전용 초안으로 변환됐지만 내부는 아직 검증하지 않았다.
- PUBG 공식 지원 문서는 WASD,Shift,Space 등 기본 이동을 뒷받침한다. 접근성/미션/NPC/현실 추상화 벤치마크는 별도 심층 조사 중이다.
- 계획 워커의 최초 외부 화재 후보는 일반 화재지침에 기반한 잠정 후보다. 2017 KORAIL PDF p168 터널 위험물 절차를 부산역 화재 역무원 절차로 옮기지 않는다.

- 직접 native 확인: Metro 지하 승강장 FPS 시점에서 외벽/천장 빈 영역을 통해 sky가 보인다. BVE 운전실 시야용 메시 범위의 한계로 분류, source asset을 보존하고 보완층 별도 제작 예정.
- fps-walk-metro-reverse.json: 실제 CharacterController StepInput으로 역방향 6지점 65.6s PASS, 텔레포트 없음. OS 입력 검증 아님.

- 추가 native: KTX FBX canonical transform 복구 후 실제 길이200.66m. 기존1670충돌체 보존. 플랫폼→외부문→전실까지 보행 도달, 객실통로는 Car02_T2 2car_08_T2-1_in_004 triangle3814 유리문 위치에서 .03498m 전방 충돌.
- KTX 영상에 레일이 객실 바닥을 통해 보이는 렌더링 오류: 혼합 알파의 깊이·정렬 원인 Astra검사 중, native 보행/완성 시각검증과 별도.
- 철도역 상부 경로 후보는 바닥4곳+개구부8곳을 제안했으나 7개 장벽의 실제 용도가 확인되지 않음. root는 무조건 절단을 보류하고 원본 공간구조 재검토를 지시.
- Metro 남은 천장 하늘 노출: source RoofL/R 폭5.6m, 벽까지각6.4m gaps. 원본RoofCL/CR 명령이 누락된 가능성, 새벽이 아닌 원본 복원 우선.

- 중요 반증: 부산시2019-06-28 공식보도는2019-07-01 KTX↔도시철도 지하통로 실제개통을 명시. L99.6/W8, 양방향M/W50m,E/S4,E/V1. 기존Exit6추정통로는 이 실제연결을 검증한것아님. 2013계획L85.8/E/S2는준공시점과다르므로분리.
