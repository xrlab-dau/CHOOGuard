## Research Findings

- KORAIL Retail's public commercial-facility board contains 4,211 historical notices and supports server-side keyword search. The specialist-store board is separate from convenience-store operations, so both must be searched.
- A 2026-05-20 KORAIL Retail youth-startup notice establishes a real 1F waiting-hall food unit at Busan Station with 52.0 m2 offered area. It is a site-area/topology lead, not yet a drawing; the original notice's attachments are the priority acquisition target.
- A current recruitment listing corroborates a Pascucci unit on Busan Station 2F, but recruitment text is branch/floor identity evidence only.
- The KORAIL Retail regional-office page is contact/location information, not a tenant list. The separate public `store/selectBoardList.do` endpoint should be queried for exact store identities.
- Public 2025 social-enterprise short-term retail documentation confirms two Busan Station temporary-store placements historically, but its available document is a program brief with photos, not an architectural plan.
- Grid-A 4U, the original interior designer/all-turnkey contractor, publishes a B&C Bakery Busan KTX proposal package dated 2021-10-25. Original sheets identify a 1F, 57.0 m2 unit and include a dimensioned floor plan, reflected ceiling plan, and three elevations. Readable major chains are about 7,490 x 8,127 mm; elevation widths include 7,602/7,490 mm and a 3,470 mm height. Printed zones are sales 19.9 m2, service 22.7 m2, and factory 14.5 m2.
- The measured B&C plan shows an open front entrance, front/right sales, left/center service counter, rear factory, and an escalator/fire-door condition at the right boundary. This is a useful local registration candidate, not a station-wide control.
- The Grid-A portfolio page says 2F, while the original cover, scope sheet, and plan say 1F. The drawing package is controlling for what was proposed, but neither source establishes a current location. Same-portfolio completed photos are implementation evidence only within that portfolio; an independent current storefront match remains absent.
- A second Grid-A B&C portfolio is explicitly 2F, 90 m2, and labeled project year 2023. Ten downloaded images include completed photographs and undimensioned renders with useful overlapping views of glazing, counter, refrigeration, window seating, lighting, and exit signage, but no metric plan.
- KORAIL Retail's live store search returned eight Busan Station operator-managed listings: five Storyway convenience units across 1F/platform and 2F waiting-room zones, Pascucci 2F, Cafe Storyway KORAIL Lounge 2F, and a new-waiting-room Storyway. These are positive current floor/zone identities, not an exhaustive tenant census or geometry source.
- KORAIL Retail's archived specialist notice catalog proves a 76.6 m2 2F waiting-hall target drawing existed, but its legacy public download returned zero bytes. The current 2026 1F 52.0 m2 target-location-map endpoint returned an HTML error. Both remain high-value public-record acquisition gaps.
- A stale SlidePlayer mirror exposed search-cache OCR for a historic 2F KORAIL commercial plan, but the domain now returns NXDOMAIN. It is useful only as historic topology and tenant-name search seed material.
- YouTube metadata verifies a continuous Busan Station interior walkthrough segment from 00:41 to 11:20 in a video uploaded 2023-05-01. Ranged media acquisition returned HTTP 403, so exact shop/landmark timestamps were not asserted.
