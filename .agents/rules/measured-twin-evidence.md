# 측정 트윈과 객체 조작의 근거 (2026-10-08 승인)

- 사용자가 승인한 목표는 실제 설치 위치와 접근 가능한 전체 맵의 가동 객체 조작이다. 벽/바닥/천장/기둥/점포 경계/건축구조도 전체 실내 디지털 트윈 모델링 범위에 포함한다. 구조 배경이라는 분류는 개별 가동 조작의 예외일 뿐 모델링·복원 제외가 아니다. 임의 훈련 배치로 현장 자료의 공백을 채우지 않는다.
- 0.02m는 프로젝트 검증 목표다. 독립 현장 측량·새 단일 기준 시점 없이 달성했다고 쓰지 않는다. 공개 자료는 직접 수집하되 reference_only를 유지한다.
- 새 설비 배치는 `PlacementVerification`의 객체/시점/Unity 좌표계/실측 출처/정합점과 분리된 검증점/세 축 치수 검사를 통과해야 한다. Editor는 파일 해시와 원본 명세에서 재생성한 worker 결과를 대조하며 실제 모델 축척을 검사한다. Runtime은 설치 인스턴스를 다시 검사한다.
- 스테이징 Blender 계층이나 photogrammetry 메시를 검증된 생산 배치로 자동 승격하지 않는다. 모델의 반복 노드나 사진 장수를 실제 가동 객체·독립 측량 개수로 세지 않는다.
- 구동부는 실재 부품/피벗/경로를 명시적으로 연결한다. 없는 객실·샤프트·리턴 경로를 합성해 가동 완료로 표시하지 않는다. 운행 정지, 탑승 이동, 표면/부품 위상은 같은 구동 상태를 따른다.
- 조작은 운영/비상 제어와 객체 애니메이션부터 구현한다. 내부 정비/볼트 분해와 아바타 손/전신 연기는 후속 범위다.
