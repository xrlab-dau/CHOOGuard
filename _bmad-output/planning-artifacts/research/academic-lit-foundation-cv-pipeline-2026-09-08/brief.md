# 최신 CV 기반 Foundation 연결 연구 — 로컬 구현 재개

> 2026-09-08 VARCO 전환으로 일시 중단한 뒤, 사용자가 비용 때문에 VARCO를 폐기하고 CV 파이프라인을 현재 로컬 세션에서 재개하도록 명시했다. 기존 조사를 재사용해 sequence spec의 CV-01~06을 구현하며 새 문헌 조사 주기를 다시 열지 않는다. 학교에는 별도 고부하 작업을 배정한다.

- 기준일: 2026-09-08 KST. 유형: 구현 선택을 위한 scoping review; 체계적 문헌고찰·독립 벤치마크가 아니다.
- 결정: 실제 단안 순회 영상의 관측 복원과 재사용 가능한 객체/공간 표현을 Blender 편집본·Unity 검토 장면까지 연결할 방법을 고른다. 오브젝트마다 유료 생성 호출을 하는 경로와 벤치 파라미터 변형만 늘리는 경로는 이번 우선순위가 아니다.
- 사용자 의도: 최신 CV 논문·연구를 확인하고 적용하여 재사용형 파이프라인을 구현하라는 반복 명시 요청과 재개 지시를 따른다. 기존 BMAD Step3를 재렌더하지 않는다.
- 연구 방법: 부모가 문헌 검색·순위를 직접 담당한다. Exa(원문 발견), alphaXiv 및 OpenAlex(orx 검색), 원 논문·공식 코드·HF 파일 메타데이터를 사용한다. 검색에 시설 이미지·기하를 보내지 않는다.
- 검색 범위: 2025-01-01~2026-09-08. 최근 6개월 연구를 우선 살피되 기존 모델과 기법의 원 출처도 보존한다. 논문 발표/학회 채택/실행 코드/가중치 공개는 별개로 기록한다.
- 세 관점: (1) 길어진 영상의 국소 복원·중첩 정합·루프 및 동적 영역, (2) 객체 분리·식별·관측과 생성 보완의 구분, (3) 기하 검증·mesh 표현·Blender/Unity 전달.
- 예산: 1차 폭넓은 발견 후 구체적인 누락에 한해 최대2회 후속 발견. 핵심 원문 3~5편과 관련 코드/조건에 집중한다. 검색 범위 내 최고라는 단일 순위를 임의 작성하지 않는다.
- 평가: 입력 센서/카메라 보정 유무, 공개 코드·체크포인트·라이선스, 실내 평가셋/프로토콜, 동적/반사/저시차 실패, 메모리·CUDA 의존, 산출물의 편집성, 재현 비용. 서로 다른 데이터·장치의 수치를 종합 순위로 합치지 않는다.
- 프로젝트 제약(외부 연구 사실의 증거 아님): 기존 로컬 DA3와 MapAnything 원시 결과, 독립 SfM 음성 결과를 보존한다. M1/16GiB에서 가벼운 실행을 하고 무거운 CUDA 단계는 학교 실행 후보로 분리한다. 훈련 Collider·실측 등록·시각/개인정보 수용은 자동 생성 성공으로 대체하지 않는다.
- 산출물: 출처 digest, 후보/실행 가능성 기록, 적용 결론 research.md, 기존 구현 spec의 추적 가능한 후속 범위와 실제 실행 증거. 글만 쓰고 전체 구현이 끝났다고 보고하지 않는다.
