# 부산역 시설 근거 추가 조사

- 요청: KORAIL 개념·배치도, 최신 평면·준공·대피·설비 도면, 안전장비 목록/사용 지침을 공식 자료부터 찾는다. 미확보 영역은 원 게시자의 브이로그/SNS 사진·영상으로 보완한다.
- 범위: KORAIL 부산역, 부산교통공사 1호선 부산역(113), 유라시아플랫폼/지하연결통로를 별도 시설로 취급한다.
- 이번 작업: 진행 중인 자료조사의 후속 수집. 구현·Unity·BMAD build renderer 재실행은 하지 않는다. 기본 조사 노력 standard, 검증 normal. 추가 에이전트 없이 직접 조사한다.
- 차원: (1) 공식 건축·배치 자료 (2) 대피·장비·사용 안내 (3) 원본 영상·사진. 이미 수행한 검색의 유망 원문을 좁혀 읽는다.
- 제약: Exa fetch 무료 한도 오류를 기록하고 반복 호출하지 않는다. 공개 원문에 직접 접근한다. 인증·유료벽 우회, 정보공개청구 제출, 외부 게시, 영상/기하의 외부 LLM 전송은 하지 않는다.
- 원본은 ignored `private-data/facility-sources/` 아래 저장한다. 공개 보고서는 출처·날짜·분류·상대 경로·해시·제한만 포함한다. signed media URL/쿠키는 공개하지 않는다.
- 완료 기준: 확보 파일과 실패를 구분한 영수증, 실제 자료 유형/최신성/사용 범위 표, 원 게시자/게시일/촬영일 분리, 부족한 자료와 요청 기관 목록. 파일 개수는 도면 수나 재구성 성공 수가 아니다.
- 검증 한계: 원문 단일 출처 확인과 독립 교차검증을 구분한다. 재구성·현장 안전절차·실측 정확도는 이 조사로 승인하지 않는다.
