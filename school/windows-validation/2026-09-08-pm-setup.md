Blender 공식 MSI SHA256은 `65d9fd64fa58d5ec25a2e315cac68ba7d3584d4c8c2757947e993c47f2fa085f`다. Blender Foundation 서명과 Unity Technologies 서명을 확인했다. Blender의 첫 무인 설치는 관리자 권한 부족(Error 1925, exit 1603)으로 실패했고, UAC 승인을 받은 재실행은 exit 0이었다. 설치 파일·원시 로그·계정 자격은 이 문서에 포함하지 않는다.

새 터미널에서 `gh --version`, `blender --version`을 사용할 수 있다. Unity Hub에서 저장소 루트를 추가하여 **6000.3.23f1**로 연다. 기존 생성 장면은 `Assets/CHOOguardGenerated/FoundationDemo/FoundationDemo.unity`이며 필요할 때 `CHOOguard > Foundation > Build Playable Demo`로 재생성한다.

Windows 실행 파일은 로컬 `Builds/FoundationDesktop/ChooGuardFoundation.exe`다. 실행 파일 하나만 옮기지 말고 같은 폴더의 Data와 DLL을 함께 보관한다. 빌드 폴더는 Git에서 제외된다.

원시 로그, XML 결과, 보드 스냅샷, 재생성 자산 diff/hash는 로컬 ignored `private-data/school-runs/windows/2026-09-08/`에 보존한다. 빌드가 재생성한 22개 scene/material/prefab 파일은 그 diff와 hash를 보존한 후 Git 기준으로 복원했다. 실행본과 PlayMode 결과는 해당 빌더 생성물에 대한 증거이며, YAML을 손으로 수정하지 않았다. 정제 수치와 소스 해시는 [검증 기록](2026-09-08-validation.json)에 있다.

수정은 세 가지다: PowerShell 5.1이 한글 스크립트를 파싱하도록 UTF-8 BOM 추가, Unix 전용 geteuid 시험을 플랫폼 공통 접근 거부 주입 검사와 POSIX 실기 검사로 분리, context의 경로 이탈 검사와 실제 symlink 생성 검사를 분리했다. 운영 검증기의 접근 거부 규칙이나 게임 코어는 변경하지 않았다.

HMD 실기, 수동 WASD/마우스 완주, 장시간 FPS/메모리 평가, 실제 시설·매뉴얼/현장 전이 수용은 미실행이다. 이번 작업에서 공개 댓글·원격 push·새 PR·이슈 종료·보드 변경은 수행하지 않았다. 학교 독립 제작은 기존 인계 경계를 따르며 별도 로컬 세션의 CV runner/export를 수정하지 않았다.
