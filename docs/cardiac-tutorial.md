# 심정지 대응 조작 학습 · Issue322

선택한 심정지 튜토리얼에만 고정 사건과 단계 안내를 적용한다. 자율 근무의 난수 사건·원래 기관 출동/자동 인계 정책은 유지한다. 역사의 원래 철도경찰 앞 AED를 사용하고, 같은 층의 실제 바닥·NavMesh·장애물·시야와 짧은 왕복 경로가 확인되는 지점에서 시작한다. 준비가 실패하면 미이수 안내와 재시작/타이틀을 제공한다. 임시 장비나 관통 이동으로 실패를 숨기지 않는다.

## 학습 범위

1. 안전한 통로에서 반응 없는 승객을 발견하고 E로 반응 확인.
2. Q 무전의 요청·기관에서119 구급 요청. 관찰한 위치와 반응만 전달하고 동료가 신고를 담당한다.
3. E로 정상 호흡 유무 확인. 일반인 맥박 확인은 요구하지 않는다.
4. 표시된 가슴 옆자리로 실제 이동한 뒤 환자에 R로 가슴압박 시작/중단. 기존 동료 rig의 팔·재질·본 길이를 재사용한다. 압박 중 시점이 낮아지고 팔은 플레이어 시점에서 이어지며, 중단·이동·교대 때 기존 시점으로 복원한다.
5. 압박 조작을 익힌 다음 압박을 유지하며 동료에게 교대 요청. 동료는 사건 시작부터 실제 같은 층의 떨어진 위치에 있으며, 약40초 걸리는 기존 통로를 걸어온다. 호출과 동시에 눈앞에 생성하지 않는다. 30~60초의 접근 동안 압박을 이어가고 실제 접근·안정된 무릎 자세·손 접촉 후 교대하며 AED 이동 중 동료가 압박을 이어간다. 발의 수cm 오차로 교대가 막히지 않도록 도착과 손 접촉을 별도로 확인한다.
6. 원래 AED 위치에 목표 표식/바닥 경로를 표시한다. E로 꺼내 운반하고 환자 곁에 놓고 뚜껑을 연다.
7. 패드2장을 각각 집고 부착 조작을 연습한다. 환자와 동료의 접촉을 멈추고 분석한다. 충격 필요 판정과 충전 후 버튼을 누르고 환자로 시선을 옮겨 R로 즉시 압박을 재개한다.
8. 구급대 도착 대기 시간을 교육용으로 줄였음을 명시하고 실제 접근을 보여준다. 플레이어가 구급대장에게 인계해야 완료된다. 대기만으로 자동 이수되지 않는다.

Q/E/R/G/Esc는 제품 입력을 사용한다. 본체에서 R은 장비 들기이므로 압박 재개와 구분해 안내한다. 의도하지 않은 회수는 설명을 먼저 보여주고 재입력으로 확인한다. 목표·이유·조작·다음 행동, AED의 마지막 안내를 일회성 알림과 별도로 유지한다. Esc에서 명시적 연습 중단은 미이수로 끝난다.

## 공식 근거와 교육용 재구성

질병관리청 [2025 한국 심폐소생술 가이드라인 및 정오표 게시물](https://www.kdca.go.kr/bbs/kdca/49/309908/artclView.do)의 성인 기본소생술을 확인했다. 아래는 책자 인쇄 쪽수이며 PDF 페이지 번호는18을 더한다.

- p54,57,60–65: 현장 안전, 반응 확인, 반응이 없으면119 신고와 AED 요청, 호흡 확인, 반응·정상 호흡이 없을 때 압박. 일반인의 맥박 확인을 넣지 않는다.
- p66–70,82–83: 가능한 도움을 받아 압박 중단을 줄이고, 성인 압박은 분당100–120회·약5cm·완전한 이완. 동료가 실제 교대한 뒤 장비를 가져오는 협업은 이 원칙의 교육용 재구성이다.
- p57,79,82–83: 맨가슴에 패드 부착, 분석·충격 중 접촉 금지, 충격 또는 충격 불필요 판정 후 즉시 압박 재개, 보통2분 후 재분석.
- p57,78,82: 충격이나 시간 경과만으로 회복을 단정하지 않는다. 회복 징후나 구조대 교대까지 대응을 지속한다.
- 정오표의 p125 전문소생술 도식 오기는 위 기본소생술 범위를 바꾸지 않는다.

이 자료를 코레일 현행 역무원 SOP로 단정하지 않는다. 역무실 통신 문구·동료 배치·역무원 직접 인계는 역할 학습을 위한 재구성이다. 실제 기관별 신고·인계 역할과 자격 요건의 운영사 SOP 일치는 미확인이다.

## 명시적 미구현과 게임 튜닝

- 사용자 선택: 기존 의복 승객 모델을 유지한다. **의복 제거/맨가슴 노출 표현은 미구현**이다. 시작, 패드 단계, 결과에 한계를 표시한다. 의복을 벗겼다고 기록하거나 모델 위 조작을 실제 맨가슴 부착 완료로 주장하지 않는다.
- 손과 가슴의 왕복 움직임은 시각 피드백이다. 실제 임상 깊이·관류·환자 소생 효과를 측정하지 않는다.
- 가슴 표면과 패드 연습 위치는 기존 환자 메시의 실제 현재 자세에서 한 번 샘플링한다. 원본 메시를 변경하거나 의복 제거를 수행한 것으로 기록하지 않는다. 팔 길이로 닿는 범위에서 시점을 정하며 본을 늘리지 않는다.
- 환자·동료·처치 구급대원의 본은 시야 밖에서도 갱신한다. 상호작용 판정이 화면 밖에서 멈추지 않도록 하는 학습 전용 정책이며, 일반 군중의 최적화 설정은 유지한다.
- 최초6초·재개8초는 조작 습득을 확인하는 짧은 표본이며 자동으로 멈추라는 지시가 아니다. 동료의 실제 교대나 AED 지시까지 압박을 계속한다. 임상2분 압박 주기나 생존 기준을 대체하지 않는다. 동료 약40초 접근은 실제 동선에 따른 게임 튜닝이며 의학적 교대 주기를 의미하지 않는다. 구급대 도착 대기 축약을 별도로 알린다.
- 이 수업은 가슴압박소생술과 AED 조작으로 범위를 명시한다. 정기적인 ‘몇초 압박 후 몇초 휴식’은 가르치지 않는다. 공식 지침의30:2는 인공호흡을 포함한 표준심폐소생술에서 압박30회 뒤 인공호흡2회를 시행하는 비율이다. 인공호흡 미구현 상태에서 가짜 휴식으로 이를 대신하지 않는다. AED 분석·충격·실제 교대의 중단은 최소화한다.
- 가슴압박과 AED 조작에 범위를 제한한다. 인공호흡30:2, 완전한 CPR 인증, 임상 역량 평가는 제공하지 않는다.
- 기기 충격 필요 판정은 시뮬레이션 규칙이며 실제 ECG 판독을 구현하지 않는다. 분석/충전/접촉 금지/재개는 기기 상태 전이를 따른다.

## 검수

기존 AED 상태 전이 회귀 검사와 실제 역 씬의 고정 시작·동선·건너뛰기 방지 검사를 실행한다. 소스 검사나 상태 플래그만으로 손 접촉, 조작성, 화면 가독성을 통과로 선언하지 않는다. 독립 코드 검토와 로컬 실행 결과를 구분하고, 최종 사용감은 사용자 플레이 승인을 받는다. 자유 모드, 원래 지도, 중단된 화재/승무원 WIP 보호도 별도 확인한다.
