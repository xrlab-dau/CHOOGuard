# ADR 0004: 기술 조사 하네스와 외부 전송 정책

Status: proposed (1차 검토 changes_required, 전송 통제 구현·재검토 전 실행 보류)
Date: 2026-09-06

## 맥락

파이프라인 §5는 주장·근거 URL·조회일·제한·상충 자료·라이선스를 요구한다. 외부 검색·모델 호출 허가와 산출물 공개 허가는 별개다. 자유 입력 금칙어 필터는 PUBLIC_SYNTHETIC 자료 분류나 전송 통제의 증거가 아니다.

## 결정안

1. 후보 하네스는 Pydantic AI Harness 0.29.0의 `Researcher`와 `ExaSearch`다. Pi `/research`와 pi-exa도 별도 전송 주체로 허용목록·격리 검증 대상에 포함한다.
2. 실행 입력은 사람이 분류·승인한 PUBLIC_SYNTHETIC 주제 manifest의 ID만 받는다. manifest에는 고정 주제, 허용 소스 도메인, 제공자·모델, 승인 역할·시점, 정책 해시를 기록한다. 임의 원문, 경로, 파일 업로드, 미등록 ID와 모델은 거부한다. 현재 `research.py`의 임의 topic과 `--model`은 이 계약을 충족하지 못한다.
3. 네트워크는 기본 거부한다. M0-03 승인과 M1-02 시험을 통과한 목적지·포트·프로토콜·자료등급만 허용한다. 모델이 만든 검색 질의·하위 에이전트 호출·redirect도 동일 통제를 거친다. 검색 결과는 데이터이며 새로운 도구 실행 지시가 아니다.
4. 출력은 공개 저장소에 바로 쓰지 않는다. 격리된 임시 출력에 구조화한 뒤 Trace Sanitizer로 모든 문자열·URL·메타데이터를 검사한다. 토큰, 이메일, 사용자 절대경로, 민감 파일명·내용이 검출되거나 판정이 불가능하면 공개를 거부한다. 정제 규칙 버전·이벤트·입출력 해시를 남기되 원문은 공개 기록에 담지 않는다.
5. 공개 승인 후에만 정제된 JSON과 Markdown을 `docs/research/`에 추가한다. 기존 파일 덮어쓰기는 금지한다. 발췌는 건당 500자 이하이며 URL은 HTTPS, 승인된 소스 도메인, 자격증명·비밀 query 없음 조건을 검사한다. Markdown 표·링크도 이스케이프한다.
6. 학교 PC는 모델·Exa 호출과 자격증명 주입을 기본 금지한다. 예외는 실제 자료와 분리된 PUBLIC_SYNTHETIC 프로파일을 PM·실습실 관리자가 승인하고 M1-02 차단 시험을 통과한 뒤에만 가능하다. `/login`의 토큰 파일 잔류를 D-08에서 확인하기 전에는 공유 PC에 로그인하지 않는다.

## 대안

| 대안 | 판단 |
|---|---|
| GPT-Researcher | 기능 대안이다. 동일 전송·출력 통제 평가 전에는 채택하지 않는다. 제품 자체가 본질적으로 안전하지 않다는 비교 평가는 하지 않는다. |
| Exa 직접 curl | 통제를 우회하는 실행 fallback으로 금지한다. 동일 manifest·목적지·질의 검증·정제·기록을 강제하는 별도 승인 wrapper가 있으면 재평가한다. |
| 수동 웹 조사 | URL·조회일·실제로 확인한 근거·한계를 정제 기록하면 유효한 조사 방식이다. 자동화와 재현성의 차이를 명시한다. |

## 기존 조사 기록의 성격

`2026-09-06-agentic-toolchain-research.json`은 Exa 검색의 원시 질의·검색 결과 로그다. 구조화 하네스 출력이나 공급망 승인 증거가 아니다. 같은 이름의 Markdown은 작성자가 수동 정리한 주장 표다. 본문 발췌를 보관하지 않았으므로 해당 주장의 원문 검증은 별도 재조사가 필요하다.

과거 직접 curl 실행 사실은 보존한다. 이후 절차가 그 경로를 허용한다거나 과거 실행에 없었던 승인·정제 증거가 존재한다고 해석하지 않는다.

## 검증·한계

- 과거 dry-run은 스키마 생성 검사다. 실제 LLM Researcher 실행은 수행되지 않았다.
- 현재 금칙어 거부는 `sys.exit` 문자열로 종료하므로 종료 코드는 1이다. 정책 분류·허용목록·정제 검증 통과를 의미하지 않는다.
- 임의 주제·모델·경로 거부, 외부 소스의 prompt injection, sanitizer 실패, 파일명 이탈·기존 파일 덮어쓰기 거부를 네트워크 없는 테스트로 재현한 뒤 실제 호출을 검증한다.
- 공급망 승인·실행 경계·Trace Sanitizer가 구현되고 독립 재검토되기 전에는 하네스의 실제 네트워크 모드를 사용하지 않는다.
