# ADR 0002: 에이전틱 개발 도구 체인 고정

Status: proposed (1차 changes_required, 공급망 승인·수정 후 독립 재검토 미완료)
Date: 2026-09-06
Supersedes: 없음. ADR 0001을 보완한다.

## 맥락과 제약

파이프라인 v1.2의 단계별 도구 선택을 머신·실행 주체·공급망 검토 대상으로 구체화한다. 표의 선언 버전과 실제 설치 관측, 허용 승인은 서로 다르다. 도구의 최신성 자체를 품질 또는 안전 근거로 삼지 않는다.

| ID | 제약 | 출처 |
|---|---|---|
| K-01 | 소스·설치 스크립트·전체 의존성·배포물 무결성 검토 전 실행 금지 | AGENTS.md, 파이프라인 §6.1, 명세 004 |
| K-02 | 다른 제공자·모델·분리 세션의 독립 검토, 실제 호출 검증 | AIN-01, ADR 0003 |
| K-03 | PUBLIC_SYNTHETIC만 승인된 외부 목적지로 전송 | 파이프라인 §6, ADR 0004 |
| K-04 | 공개 설정은 Git으로 전달하고 Unity 실행은 school-pc만 | 발견 A-07, Q8 |
| K-05 | 라이선스 원문·고지·vendored 재배포 의무 검토. 미판정은 비허용 | 명세 004 FR-004 |
| K-06 | Git Flow 브랜치와 명세 디렉터리를 별개로 관리 | docs/branching.md |

직접 버전 고정만으로 동일 설치가 재현되지 않는다. 별도 추적 npm manifest·전체 lock·resolved·integrity와 검토된 설치 절차가 필요하다. ignored `.pi/npm` lock은 유일한 근거가 될 수 없다. 조사 pyproject·uv.lock도 정책 해시에 포함한다. 현 버전 검증 영수증은 이 요구의 완료 증거가 아니다.

## 위협·비용·복구

| 위협 | 필요한 통제 | 현 상태 |
|---|---|---|
| 공급망 변조·설치 스크립트 부작용 | 전이 그래프·배포물 hash·source revision·라이선스·목적지 검토 | 미완료 |
| 조사 전송·미정제 게시 | 승인 주제·실제 모델·모델 밖 egress, 격리 출력·정제·공개 승인 | 금칙어 필터만으로 불충분, 실행 보류 |
| 보호 파일 자체 수정 | OS 실행 경계와 승인 gate. CODEOWNERS는 병합 통제이지 로컬 쓰기 sandbox가 아님 | 보호 소유권·차단 시험 미완료 |
| 필수 리뷰 실패의 승인 축소 | 모든 관점 성공·manifest·실제 모델 검증 | 현 YAML fail-open, 운영 보류 |
| 공유 PC OAuth 토큰 잔류 | 별도 사용자 프로파일·저장 위치·로그아웃 잔류·철회 검증 | D-08 미정, 로그인 금지 |
| MCP Editor 임의 실행 | 공급망·실행 경계·도구별 승인·Writer Lease | 미설치·미검증 |

비용은 모델과 Exa의 실제 사용량·요금제로 산정한다. reviewer, reducer, 수정자, 중첩 호출, 재시도를 별도로 센다. 설치 시간·예산은 학교 PC 환경과 목적지 승인 전 추정치를 확정하지 않는다. 현재 초기 리뷰와 `max: 3` 루프는 총 3라운드 목표와 불일치한다.

복구는 단순 Git 되돌리기가 아니다. 우선 프로세스·전송을 중단하고 PM이 설치·로그·자격·파일 변경 범위를 조사한다. 전역 설치·토큰·외부 전송은 Git으로 취소되지 않는다. 보호 설정 변경·캐시 삭제·자격 철회는 별도 사람 승인으로 수행한다. 기존 증거는 보존하고 승인 없이 `.pi/npm`이나 가상환경을 삭제하지 않는다.

## 검증 게이트

M0-00의 사람 정적 검사, M0-03 공급망·허용목록, M1-02 실행 경계, M1-03 MCP 검토, M1-07 독립 리뷰 경로를 각각 완료해야 한다. 문서 작성·패키지 설치 관측·YAML 파싱으로 이 게이트를 통과시키지 않는다.
