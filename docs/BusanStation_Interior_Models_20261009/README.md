# 부산역 내부 구조 복원 작업물

`BusanStation_2F_Architecture.blend`는 Unity에 실제 적용한 2층 도면 벽 56개와 원본 기둥 53개, 기존 모델의 높이로 추정한 하단 기둥 4개를 개별 편집 가능한 메시로 저장한 파일입니다. 172개 벽 선분과 30개 개구부를 하나의 공식 도면 픽셀 좌표계로 결합했습니다. 계단 표시 4개를 불투명 벽으로 잘못 돌출했던 부분도 수정했습니다. 도면의 X 영역을 잘라낸 실제 Unity 바닥 메시도 포함해 총 114개 오브젝트입니다. 원본 텍스처 6개를 파일에 포함했습니다.

이 파일은 부산역 전체 내부의 완성본이 아닙니다. 현재 높이는 실측값이 아니며, 4층과 5층 전체 구조를 검증할 자료도 확보되지 않았습니다. `99% 일치`가 검증되었다는 의미로 사용할 수 없습니다. 실제 적용 씬은 `Assets/ChooGuard/Scenes/FpsStation.unity`입니다.

1층 도면의 벽·문·기둥·실 구획·화장실을 분리한 원본 SVG/DXF/JSON은 `workers/twin/output/floor1-architecture-source-trace-20261009/`에 있습니다. 원본 도면의 분리 삽입 도형은 현장 위치가 확인되기 전까지 임의로 본관에 붙이지 않습니다.

`BusanStation_1F_Architecture.blend`는 제공된 1층 PDF에서 검토한 본관 벽 57개를 모서리 중첩 없이 합친 54개 편집용 메시입니다. 개구부 52개의 선형 통과 검사에 모두 통과했습니다. 층간 기둥·승강기 코어 대응으로 2층과 같은 좌표계에 정합했으며, 검증점 오차 RMS는 원도 기준 0.762픽셀입니다. 높이 6.7은 기존 모델의 2층 슬래브 하단 기준이며 현장 실측값이 아닙니다. 동일한 벽 메시를 FpsStation 씬에 실제 적용했고, 벽 54개와 개구부 52개의 물리 검사는 통과했습니다. 기존 군 관련 상담실 벽 한 곳이 출입구를 가리는 문제는 별도로 수정 중입니다.
