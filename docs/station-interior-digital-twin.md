# 부산역 1·2층 내부 공간 이관

현재 저장 씬은 `Assets/ChooGuard/Scenes/FpsStation.unity`다. 1·2층 내부 형상, 점포·집기, 화장실, 이동시설, 재질과 직접 제작한 입체 글자 모델을 함께 이관한다. 실제 객체별 편집 구조와 원본 에셋 GUID를 유지한다.

현재 CAD는 `.state/CURRENT-2F-VECTOR-CAD-R26.json`이 가리키는 snapshot008 PDF·DXF·JSON이다. 현재 31,636개 렌더러와 3,817개 고유 메시에서 생성했으며, 공식 형상 78개와 현재 배치 모델을 포함한다. 대체 렌더 LOD1은 제외하고 원본 LOD0을 한 번 반영한다. 도면은 현재 형상 참조이며 새로운 사용자 확정이나 바닥 점유 권한이 아니다.

확인된 글자 표면 320곳과 꽃들 간판을 닫힌 입체 글리프로 교체했다. 벤치 28개의 코레일 로고·우선배려석 안내도 입체 메시다. 글자용 이미지 면, TextMesh·TMP·글꼴 아틀라스를 새 모델의 대체 표현으로 사용하지 않는다.

부스·원본 건축 형상, 승인된 바닥 외곽과 이동시설 개구부, 사용자 삭제·수정 내용을 보존한다. 삭제한 Light·Text/TMP나 과거 점포 배치를 이전 시공 스크립트로 되살리지 않는다. 체크포인트 1의 폐기한 프로젝트 복제본과 사용자가 삭제한 과거 1층 작업 문서도 복원하지 않는다.

사진·영상·원본 설계 자료의 촬영/설계 시기와 MODEL 치수를 구분한다. 가려진 부분의 동일 모델 재사용과 미실측 치수는 실측 99% 일치로 주장하지 않는다. 현재 시공 및 저장 영수증은 `state/evidence/2026-10-19-interior-digital-twin.json`과 작업 등록부에 연결했다. 사용자가 씬 외형을 검토하며 CI의 소스·도구 검사는 이와 별도다.

다른 PC에서는 Git LFS로 큰 씬·메시·CAD를 받은 뒤 FpsStation을 연다. 씬에 설치된 provider 게임 런타임과 기존 기능을 보존하며 날짜가 붙은 설치기를 재실행하지 않는다. 계정·토큰·capability·원시 Runs와 로컬 작업 큐는 이관하지 않는다.

게시용 조사 메타데이터에서는 네이버 카페 URL의 `art`와 영상 재생 `data.inkey` 임시값을 제거한다. 원문·영상 식별정보와 로컬 원본, Scene·Assets·CAD 형상은 보존한다. 정확한 변경과 SHA-256은 `state/evidence/2026-10-20-public-source-sanitization.json`에 기록하며, 기기별 데몬 실행 상태는 게시하지 않는다.
