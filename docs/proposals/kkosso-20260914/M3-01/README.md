# M3-01 공개 자료 취득 체크리스트 준비안

기존 #28 prepare 착수를 마무리하는 검토용 자료입니다. 13구역의 식별자·이름은 기준 커밋의 facility-coverage 목록과 정확히 맞췄습니다. 과거 도면 ID는 문맥 탐색용이며 자료 재취득·권리 확인·복원 재개를 뜻하지 않습니다.

각 행은 필요한 view, 해상도 판단 기준, 시점·가림, 정확한 관찰과 추정의 구분, 증명할 수 없는 항목을 담습니다. 실제 취득·현재 권리·정밀도는 미확인 상태입니다. 근거 없이 픽셀 수나 시설 치수를 정하지 않았습니다.

#15의 자료별 사용조건 candidate가 아직 없어 취득 단계는 진행하지 않았습니다. `gaps.json`의 선행 자료와 재개 순서를 확인한 뒤 새 candidate claim을 작성해야 합니다. 이 준비안을 공식 취득 결과 또는 13구역 완료로 승격하지 않습니다.

검사: 구역 13개와 식별자 유일성·기준 목록 순서, 모든 행의 view 및 미확인 상태, checklist와 gaps의 구역 일치, 입력 Git blob과 출력 파일의 SHA-256을 확인했습니다. 이미지·Unity·모델링 실행 대상 변경은 없습니다. 장비 소유·위치·특정 담당자를 착수 요건으로 두지 않습니다.
