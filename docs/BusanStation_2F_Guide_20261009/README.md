# 부산역 본관 2층·맞이방·승강장 통로 안내도 대조 및 수정

대상 씬은 `Assets/ChooGuard/Scenes/FpsStation.unity`다. 안내도와 공개 현장 사진을 대조하여 확인된 구조 차이를 실제 메시, 충돌체, 문 위치와 길찾기 데이터에 반영했다. 이 문서는 **전체 2층이 현실과 동일하게 완성됐다는 인증이 아니다**. 전체 안내도의 상대적인 위치를 대조한 결과와 실제 저장·실행 검증을 구분한다.

## 검증과 남은 범위

최종 구조 씬 SHA는 `80a55958…`다. 네 점포의 원본 자동문 개폐를 확인했고 실제 캐릭터로 출입구 네 곳과 승강장 연결 통로 네 곳을 각각 양방향 총 8회 통과했다. 네 착지 축의 짧은 구간도 양방향 총 8회, 확인된 두 난간 우회 경로는 양방향 총 4회 통과했다. 보행 검사 캐릭터는 높이 1.72, 반경 0.30이며 실제 충돌 바닥 지지를 확인한다. 원본 디딤판에서의 운행 동작 검사는 별도 결과다.

**남아 있는 길찾기 결함:** 북측 5·6번 하부, 남측 1번 상부, 남측 3·4번 상부, 중간 8·9번 하부의 같은 층 접근이 `PathPartial`이다. 원래 운행 방향으로 두 끝점 사이 경로가 연결된다는 결과는 그 끝점까지 걸어서 접근·이탈할 수 있다는 증명이 아니다. 픽셀 해상도 증가, 경사별 차단 마스크, 축 끝점 이동 후보로 해결되지 않았으며 프로덕션에 적용하지 않았다. [상세 판정](native-passages-final-readonly-report.md)을 보존했다. 따라서 전체 역의 모든 승하차 길찾기가 정상이라고 표시하지 않는다.

검증 결과와 최종 씬 해시는 [validation.json](validation.json)에 기록한다. 통로의 실제 캐릭터 이동, 문 개폐, 길찾기 연결, 원본 메시 채널과 1층 보존 검사를 별도로 수행했다. 재생성 검증은 임시 메모리에서 시행했으며 프로덕션 전체 루트를 파괴적으로 다시 만들지 않았다.

최종 저장 씬에서 아래 **13개 테스트가 통과**했다. 이 테스트의 통과와 네 곳의 별도 NavMesh 접근 실패는 서로 다른 검사 결과다.

경로 그래프는 노드 1,826개와 간선 7,579개다. 장소로 등록된 1,441곳은 출구에 도달하지만, 지붕 등을 포함한 나머지 그래프 노드 893개는 출구에 도달하지 않는다. 이 검사로 모든 공간과 모든 승강 설비 착지점의 접근을 정상이라고 인증하지 않는다.

독립 저장 감사 [83개 검사](remaining-native-fronts-saved-audit.json)는 허용된 2층 변경만 있고 원본 `FPSWorld` 문서 18,608개와 1층을 보존했음을 확인했다. `StationDoor` 103개의 직렬화된 컴포넌트 필드를 보존했다. 원본 자동문의 위치는 유지했으며, 초기 점포 정렬 때 옮긴 생성 문 네 개는 최종적으로 비활성 보관했다. 컴포넌트 필드 보존을 모든 문 위치의 무변경으로 해석하지 않는다.

[최종 산출물 독립 검토](../../workers/twin/evidence/floor2-contract-review-20261009/final-delivery/README.md)는 테스트 실제 실행 수, 경로 그래프 수치, 실패 항목의 명시, 씬·자료 해시와 원본 문 위치 보존 범위를 재확인한다.

현재 원본에서 임시로 재생성한 본관 메시 9개와 마감 메시 9개가 저장된 보정을 재현했다([본관](all-native-main-source-regeneration.json), [마감](all-native-kit-source-regeneration.json)). 역무실의 분리한 유리도 정확한 자식 재생성과 중복 거부를 [확인](office-replay-validation.json)했다. 원본 에스컬레이터 15곳의 디딤판 정점 615개 운행 검사는 [이전 별도 실행](native-platform-motion-play.json)이며, 위의 최종 씬 테스트 13개에 합산하지 않았다.

운영자 안내도의 32개 점포와 33개 시설 표식을 대조했다. 17개 연속 점포 순서와 3개 맞이방 방향 관계는 자료와 일치한다. 시설 표식 11개는 특정 원본 개체와의 일대일 대응이 확정되지 않았다. 점포·방·통로의 폭, 높은 천장과 벽의 실제 치수, 미공개 사무실·매장 내부는 독립 실측으로 확인하지 못했다. 상세 위치별 판정은 `workers/twin/evidence/floor2-main-restoration-20261009/README.md`에 있다.

8월 안내도는 기존 간판과 여섯 점포의 명칭이 다르다(8·9·18·20·21·27번). 안내도는 해당 날짜의 명칭을 뒷받침하지만 실제 최신 간판의 모양과 내부 구조까지 증명하지 않는다. 간판 그림과 내부 구조를 임의로 제작하지 않았다. 19번 명칭은 원본 해상도에서 `꽃들`로 확인했다.

안내 데스크는 기존 원본 나무 형태 기둥 위치를 유지했다. 13·14번 점포의 위치를 단순한 좌표 이동으로 옮기면 안내도 순서가 뒤집히므로 적용하지 않았다. 높은 맞이방을 일부 카메라 위치에서 가리는 원본 상부 구조는 공개 사진만으로 실제 부재를 증명할 수 없어 제거하지 않았다.

사용한 컴퓨터 비전 자료는 안내도 경계·현장 사진의 구조 대응과 원본 면의 분리·정합 근거에 연결했다. 이 작업에서 NeRF나 3D Gaussian Splatting으로 독립 실측 수준의 내부 공간을 복원한 결과는 없다. 구조 전체의 현실 동일성은 현재 공개 자료만으로 검증되지 않는다.
