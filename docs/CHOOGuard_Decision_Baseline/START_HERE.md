# CHOOGuard 결정된 제품 방향 — 개발 AI 진입점

**제품:** 작성 담당자가 RTS·운영 시뮬레이션으로 다기관 대응안을 시험·비교하고 대본으로 내보내는 Unity PC 도구.

**이번 결정:** PRD v10을 유지하면서 기본 기술·UX·무료 자산 선택을 좁혔다. 원격 #222·work-order·코드는 변경하지 않았다.

## 읽기 순서

1. `DECISIONS.md`의 제품 정의·두 모드·개발 단계를 읽는다.
2. `decisions.json`에서 현재 EP에 연결된 결정만 선택한다.
3. `basis/contracts/epics.json`에서 같은 `epicId`를 읽고 해당 REQ/AT를 따라간다.
4. `SOURCES.md`와 `basis/free-assets.json`에서 필요한 원문만 확인한다.
5. 실제 저장소의 현재 코드·쓰기 범위·활성 작업을 읽은 후 구현을 시작한다.

**첫 작업:** EP00에서 현행 코드·사용사례·평가기준을 확정하고 EP01/EP02 운영 코어와 EP03 작은 맵의 독립 산출물을 진행한다. 첫 성공은 두 기관 협조의 A/B 실행·설명·대본 출력이다.

**두 모드:** TUTORIAL / RANDOM_OPERATIONS_LAB. 같은 물리·운영 코어. 재생·편집·검증 프로파일은 별도 사용자 모드가 아니다.

**정확도:** 초기 fixture 성공은 실물·매뉴얼·물리·현장 검증이 아니다. 계획의 확정과 제품의 검증을 구분한다.

**자료:** 기존 입력 10개는 원본 바이트와 해시를 보존했다. 신규 에셋·가중치·기관 매뉴얼을 이 패키지에 취득한 것이 아니다.

**주의:** 이 부록의 JSON은 기계 판독 결정 문서다. runtime schema validator·실행 승인·새 스케줄러가 아니다. 원 PRD의 실제 인수시험은 계속 미실행 상태다.
