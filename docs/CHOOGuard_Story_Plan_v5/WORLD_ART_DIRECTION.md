# 부산 오픈월드와 내부 공간 제작 방향

2026-09-21 사용자 확정. 활성 스토리는 `CS-EXEC.01.01` 하나로 유지한다. 최신 목표는 실제 부산역과 부산역–남포–북항의 외관·건물 내부 구조를 디지털 트윈 수준으로 복원하면서 JWE3처럼 장소와 운영 흐름이 읽히게 만드는 것이다. 이전의 시각 모델만 게임화해도 된다는 범위보다 최신 요구를 우선한다. 공개 도면·현장 사진/로드뷰·공개 3D/공간 데이터와 연결된 구조부터 교체하며, 측정 근거 없는 치수와 가려진 내부는 추정 상태를 보존한다. 현재 결과를 상용 게임과 동등한 품질로 승인한 것은 아니다.

- 외부 범위: 부산역–초량–중앙동–남포동–북항. 원도심 상가·주거, 철도, 항만, 공원의 외형을 구분한다.
- 내부 범위: **부산역 전 층 + 주요 훈련 거점 내부**. 역무·통제·대기·상업·의료지원 공간과 수직 동선을 보기 쉽게 만든다.
- 컴퓨터 use는 사용하지 않는다. Jev는 근거에 따른 선택·매개변수·결함 분류를 제공하고, Astra low가 Blender 스크립트와 Unity 코드를 작성한다. 최종 판단은 메인과 실제 산출물 근거로 한다.
- 조작과 시각 형상은 게임 목적에 맞게 조정할 수 있다. 시각적 상세도 증가를 실측 구조·환기·방재 성능·물리 검증으로 간주하지 않는다.
- 최신 추가 요구: 1 Unity 단위 = 1m로 통일한다. OSM·표고·참조 보행 공간은 미터 좌표를 사용하며 사람·문·의자·차량을 통째로 확대하지 않는다. 월드의 3D 문자와 설명 텍스트는 제거하고 UI 텍스트는 유지한다. Jev025와 `spatial-metre-contract.json`이 현재 수치 전환 근거다.

Jev019 결과와 메인 판단을 연결한 제작 패킷은 `.planning/2026-09-20-integrated-build/world-art-design-packet.json`이다. 따뜻한 콘크리트·석재, 청회색 유리, 제한된 벽돌색, 맑은 해안 오후 조명으로 방향을 정했다. 건물 유형과 지면 재질은 구역별로 배치하고, 나무·소품은 도로·건물·수면과 겹치지 않도록 제한한다. 이는 제작 결정이며 자동 품질 승인이 아니다.

공개 자료의 적용 범위

- OSM 원본의 건물·도로·철도와 해안선은 위치의 근거다. 열린 해안선이나 하천을 임의로 닫은 면으로 만드는 기존 오류를 수정한다. 초량 구릉은 역의 서측·북서측, 북항은 동측·남동측이다.
- [부산시 북항 계획](https://www.busan.go.kr/ghbusan02/)과 [부산항만공사 친수공원 자료](https://www.busanpa.com/board/view.do?boardId=BBS_0000027&dataSid=27067&menuCd=DOM_000000105001001000&paging=ok&startPage=38)는 수변·공원·광장·보행 공간 구분의 근거다. 계획 자료는 완공 현황과 구분한다.
- [부산시 용두산공원 소개](https://www.busan.go.kr/eng/park09)는 부산타워와 구릉 공원의 주요 형태를, [부산관광 자갈치 자료](https://www.visitbusan.net/index.do?lang_cd=ko&menuCd=DOM_000000201013001000&uc_seq=412)는 시장과 해안 가로의 성격을 뒷받침한다.
- 부산역 공개 시설 안내도는 층별 시설과 상대적 동선을 뒷받침한다. 세부 방 배치, 구조 부재, 실제 비상 설비 치수까지 확인한 도면은 아니다. 자료에 없는 내부 상세는 훈련 게임용 제작 형상으로 기록한다.
- [Frontier의 JWE3 환경 소개](https://blog.playstation.com/2025/10/08/jurassic-world-evolution-3-introducing-the-island-generator/)에서 지형·수면·식생 조합과 빛의 공간 표현을 참고한다. 부산 도심을 열대 공원으로 바꾸거나 동일한 렌더링 기술을 구현했다고 주장하지 않는다.

추가로 [Mapzen Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)의 공개 표고 타일 4장을 사용한다. 40m 시각 격자에서 도로·공원·건물·소품이 같은 높이 면을 따르게 한다. 역과 두 거점은 기존 내부 좌표를 지키도록 완충 영역을 둔다. 원본 표고, 기준 높이 조정과 평탄화는 별도 기록하며 현장 측량을 대체하지 않는다. 자갈치 내부에는 부산시설공단의 [공식 1층 안내도](https://www.bisco.or.kr/jagalchimarket/facil/facil01/facil01_3/)를 적용한다.

이번 검수는 실제 Unity의 넓은 시야, 중간 거리, 가까운 거리와 층별 내부 화면으로 한다. 지면과 해안, 랜드마크의 위치·크기, 모델의 겹침·떠 있음, 내부 동선과 시설 식별, 메시·렌더러 비용을 확인한다. Blender 미리보기나 오브젝트 개수만으로 완료 처리하지 않는다. 기존 물리 계산을 시각 변경 때문에 반복 실행하지 않는다.
