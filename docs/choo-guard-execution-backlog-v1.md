## 2. 공통 Definition of Done

각 작업은 **그 작업에 적용되는** 증거와 독립 검토를 충족해야 Done이다. 아직 생성 대상이 아닌 제품 증거를 초기 작업에 요구하지 않는다.

1. 요구사항·기준 문서 절 또는 ADR, 구현 위치와 해당 검증 ID가 연결되어 있다.
2. 최종 책임자 한 명, 협력자와 실행 에이전트가 기록되어 있다.
3. 변경 파일과 생성 자산이 세션 계약의 허용 경로 안에 있다.
4. 문서·승인 준비 작업은 문서·질문·승인 기록의 해시를, 통제 구축 작업은 정책·합성 시험 영수증의 해시를 연결한다.
5. Unity·맵·콘텐츠 작업은 해당 필수 자동 테스트·실기 검증이 실제 실행되어 통과해야 하며 결과 파일의 존재만으로 통과하지 않는다.
6. 제한 라이선스·민감자료·보안 변경 여부와 외부 모델 전송 여부를 해당 작업 범위에서 검사했다.
7. 작성 에이전트와 다른 제공자·모델의 독립 검토 반대가 해소되고 재검토를 통과했다. 사람 사유만으로 생략하지 않는다.
8. 해당 작업에서 관측 가능한 실행 사건과 정제 표시를 포함한 기록이 존재한다.
9. 빌드·맵·공개 후보를 생성하는 작업과 MVP 최종 게이트는 PM 통합 커밋·빌드·맵·테스트·검토 입력의 해시를 target manifest로 연결한다.
10. 외부 공개 작업은 실제 공개 파일 목록·해시가 공개 승인 범위와 일치해야 한다. 정제 통과만으로 공개 가능하다고 보지 않는다.
11. 병합·배포·삭제, 민감자료 이동·전송 또는 제한 라이선스 도입이면 사전 승인을 받았다.
12. 검토 후 적용 대상 산출물 해시가 바뀌면 영향을 받은 테스트·검토·승인을 다시 수행했다.
