# 컨텍스트 그래프의 결정 출처

이 문서는 대화에서 사용자가 명시한 프로젝트 방향을 팀이 재사용할 수 있도록 요약한다. 명령 실행 결과나 현장 수용 증거가 아니며, 최신 사용자 지시와 프로젝트 AGENTS.md가 우선한다. 그래프의 상태만 바꿔 구현 또는 검증을 완료 처리하지 않는다.

## 2026-09-07 · 현재 외형 방향

사용자는 flat 스타일을 제거하고 공개된 역사 레퍼런스를 참고하여 Blender에서 사실적인 역사 모델을 제작하도록 요청했다. 사실적인 재질·형상 방향은 승인된 목표이며, 새 모델의 제작·통합·검증 완료를 의미하지 않는다. 기존 flat 규칙은 이 외형 범위에서 폐기되었다. 실제 시설 자료가 없는 부분은 합성·미검증으로 유지한다.

## 2026-09-07 · 지속되는 시뮬레이션 방향

평상시 NPC와 설비가 운영되는 공간에서 예상하지 못한 사건을 발견하고, 조건에 맞게 대응한 뒤 같은 세계가 복구되어 다음 사건으로 이어진다. 사건 선택 메뉴나 정답 순서가 기본 경험이 아니다. Desktop을 먼저 구현하고 VR은 같은 공간 Anchor와 행동 의미를 사용한다. 동일한 대피자에게 감정·표정·직무 대행을 추가하지 않는다.

## 2026-09-07 · 프로젝트 컨텍스트의 범위

사용자는 로컬·학교 PC·팀원·서브에이전트 사이에서 사용할 수 있는 Git 기반 프로젝트 컨텍스트 그래프를 요청했다. 이 그래프는 출처·현재성·폐기된 결정을 구분하는 탐색 자료다. 개인 전역 메모리, 계정 정보, 원문 기밀 자료, 재사용 가능한 게시 승인이나 실행 권한을 저장하지 않는다.

## 폐기된 외형 결정

앞선 2026-09-07 지시는 단색·무광·면 단위 음영의 flat 스타일이었다. 당시 코드와 시험 기록은 그 범위의 역사적 자료로 남는다. 현재 작업 지시로 재사용하지 않는다. 상시 운영·직접 인솔·공통 역할 계약 등의 별도 결정은 flat 스타일 변경만으로 폐기되지 않는다.

## 2026-09-07 · 오브젝트별 재현 기준

사용자는 실제 시설 재현이 제대로 진행되는지 점검하고, 시뮬레이션에 사용하는 모든 오브젝트를 Pinterest 또는 웹에서 찾은 개별 원본 이미지에 근거해 Blender로 상세 제작하도록 요구했다. 전체 역사 사진 몇 장이나 FBX 개수만으로 충족을 선언하지 않는다. 원본에서 관찰한 형태, 제조사 대체 모델, 합성 배치·치수, 가상 UI와 실제 출력 검수의 근거를 분리해 기록한다. 이미지 참고와 자동 시험은 실제 시설 일치의 수용 증거가 아니다.
