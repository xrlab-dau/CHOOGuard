# 부산역 공개 시설도·연결 관계 조사

2026-09-07 확인. 기차·선로·승강장·터미널·매표·역사와 연결 도시철도까지 확장할 때 사용할 공개 근거의 범위를 정리한다. **현재 치수가 기입된 KORAIL 2층 맞이방 준공 평면도나 현행 선로·승강장 배선도는 이 조사에서 확보하지 못했다.** VR 확장은 확정된 방향이고 기기는 미정이다. 자료를 찾았다는 사실은 재구성 완료나 실제 배치 검증을 뜻하지 않는다.

## 시설을 구분하는 기준

KORAIL 부산역, 부산교통공사1호선 부산역, 역 앞 부산유라시아플랫폼은 구분한다. 유라시아플랫폼의1·2층 안내도는 KORAIL 맞이방이나 열차 승강장의 도면이 아니다. “터미널”은 우선 철도 여객 터미널 공용구역으로 해석하며, 별도 버스·항만 터미널을 이 자료 묶음에 추가하지 않았다.

## 스케일과 연결에 적용할 수 있는 것

현재 채택한 수치 제약은 **P04의 해당 지하연결통로99.6×8.0m**다. 이번 현장 측량값은 아니며, 통로가 보이지 않는 맞이방 A/B 사진의 스케일을 이 값으로 보정할 수 없다.1층 임대도,2층 사진, 도시철도 안내도, 광장 투시도는 공통 좌표계가 확보된 자료가 아니다.

P03의 안내도에는1~7번 출구가 보이지만 P04/P09는8·10번 출구를 안내한다. 서로 다른 개정 상태가 섞여 있을 수 있으므로 이 자료를 겹쳐 하나의 최신 탈출 경로로 선언하지 않는다. 물리 연결은 공개 자료가 보여주는 관계까지만 기록하고, 정확한 위치·층고·방향은 미검증으로 남긴다.

## 사진 및 재구성 범위

실제 DA3 입력 후보는 같은 맞이방을8초 간격으로 촬영한 두 JPEG(B→A)다. EXIF의 기종/초점거리 일치와 공통 표지기둥·트러스·전광판·벤치를 확인했다. 하부의 인물·수하물·반사 바닥을 제외하면 우선 다룰 수 있는 부분은 **맞이방 상부 한 구간**이다. 사진 밖의 차량·선로·승강장·연결통로·도시철도를 이 결과의 관측 영역이라고 부르지 않는다.

| 구역 | 현재 근거 | 재구성 상태 |
|---|---|---|
| KORAIL2층 맞이방 | 겹치는 사진2장 | DA3·Blender·Unity의 부분 표면 검토 경로 확인. 실측·체적 모델 완료는 미승인 |
| 매표/발권 구역 | 별도 단일 사진R06 | A/B와 분리. 정확한 층/접속 위치 미확인 |
| KORAIL1층 맞이방 | 2014년 임대 배치도 | 현행 형상/실측 스케일 미확인 |
| 유라시아플랫폼·광장 | 공개 시설도 | 무치수 상대 배치만 확인 |
| 지하연결통로 | 운영자 치수·연결도 | 별도 촬영/형상/접속 위치 검증 필요 |
| 도시철도 대합실·승강장 | 무치수 공식 안내도 | 세부 형상·현재 개정·공통 좌표 미확인 |
| 기차·선로·KORAIL승강장·도시철도 차량 | 이번 사진에 관측 없음 | 형식/현행 도면/겹치는 공개 사진 확보 필요 |

공개 연결도로 뒷받침되는 것은 `철도역 ↔ 지하연결통로 ↔ 지하상가/도시철도` 및 도시철도 내부의 수직 연결이다. 차량→승강장→맞이방→매표/터미널 공용구역의 게임 연결도 필요하지만, 구체적인 문과 좌표는 별도 근거 또는 명시된 합성 설계로 구성해야 한다. [구역별 상태·제안 연결·출처 해시](../../foundation/world/facility-coverage.json)를 따른다.
