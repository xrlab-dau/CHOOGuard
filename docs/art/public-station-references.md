- 확인일: 2026-09-07
- 대상: **KORAIL 부산역 지상 2층 맞이방과 매표 구역**. 부산교통공사 지하철 1호선 부산역은 이 참고 묶음의 대상이 아니다.

## 관찰 근거와 제작 목표

| 관찰 근거 | Blender 제작 목표 | 확인되지 않은 사항 |
|---|---|---|
| R02~R03의 원형 기둥·대각 부재·상부 창 | 기둥, 접합부, 트러스, 지붕 패널을 분리한 반복 가능한 한 구간 | 부재 규격, 실제 접합 상세, 기둥 간격, 천장 높이, 구조 성능 |
| R02~R03의 회색 반점 바닥·줄눈·반사·점자블록 | 별도 제작한 표면 패턴, 줄눈과 거칠기 차이, 점자블록 형태 | 실제 석재 종류, 판석 규격, 점자블록의 현재 위치와 규격 |
| R02~R03의 좌석과 가장자리 상점·난간 | 좌석·금속 다리·창틀·유리·상점 개구부의 형태 및 재료별 반사 차이 | 정확한 수량·간격·전체 평면과 현재 임대 점포 |
| R04~R05의 전광판·카운터 | 두께 있는 프레임, 곡면·작은 타공, 별도로 만든 화면·안내 그래픽 | 설비 제조사·치수·실제 기능과 동작 조건 |
| R06의 매표 구역 | 낮은 천장, 발권기·창구·대기열 벨트의 별도 모듈 | 맞이방과의 정확한 연결 위치·폭, 단말 모델·작동 방식 |

첫 작업 구역은 R02~R03의 **중앙 좌석 주변과 트러스 한 구간**으로 잡는다. 재질은 무광·반광 금속, 유리, 반점 바닥처럼 사진에서 보이는 차이를 별도로 제작한다. 사진의 인물·광고·브랜드 그래픽·운행 시각을 텍스처로 복제하지 않는다. 타 역이나 지하철역 사진을 같은 부산역 구역의 공간 근거로 섞지 않는다.

이 제작 목표는 외관에 관한 제안이다. 기존 플레이 경로·충돌 경계·좌표 변환을 바꾸는 근거로 사진만 사용하지 않는다. 경계를 바꾸는 구현은 해당 시험과 리드 검토를 별도로 따른다.

## 실제 치수와 합성 설계값의 구분

이 참고 문서는 숫자로 된 실측값이나 새 합성 치수를 확정하지 않는다. 사진의 원근과 사람 크기를 기준으로 계산한 값을 실측값으로 기록해서는 안 된다. 구현에서 필요해 정한 값은 아래 구분에 따라 모델·프로필에 명시한다.

| 항목 | 사진으로 확인된 실제값 | 합성 제작 제안값의 기록 |
|---|---|---|
| 기둥 간격·천장 높이·트러스 크기 | 미확인 | 구현 시 별도로 정하고 `synthetic_design` 및 채택 여부를 기록 |
| 통로·출입구·대기 구역의 폭과 길이 | 미확인 | 플레이·충돌 시험과 연결한 합성 설계값으로 관리 |
| 안내소·전광판·발권기·좌석 치수 | 미확인 | 물체별 작업 치수와 단위를 모델/자산 기록에 보존 |
| 사진에서 보이지 않는 구역과 연결 통로 | 미확인 | 추정·합성 연결임을 표시하고 실제 부산역 평면으로 주장하지 않음 |

각 제작값에는 항목 ID, 값·단위, 모델/프로필 버전, `synthetic_design` 또는 추후 `measured` 구분, 근거 ID, 확인 범위와 상태를 남긴다. 사진 근거 R02~R06은 형태 참고의 출처이며 수치 정확도의 출처가 아니다. 향후 승인 도면·측량 자료를 받으면 용도별 허용 오차를 정해 대조하고, 확인된 값만 실측 또는 검증된 값으로 승격한다.

이 단계의 표현은 **“공개 사진 기반 부산역 맞이방 재현 시제품 — 치수·현재 배치 미검증”**이다. 측량된 디지털 트윈, 실제 대피 경로의 적합성, 직원 매뉴얼·장치 조작 절차의 검증 또는 현장 훈련 효과를 의미하지 않는다. 공간·절차 검증은 [상시 현장 훈련 문서](../choo-guard-open-world-training.md)의 실제 자료 연결 범위와 구분해 진행한다.
