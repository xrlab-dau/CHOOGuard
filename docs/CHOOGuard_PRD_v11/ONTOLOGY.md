# 온톨로지와 인식 경계 v11

기존 v10 어휘 URI를 보존하고 versionInfo를11.0.0으로 갱신했다. 현재 JSON-LD는 설계 어휘·요구·시험·작업 관계다. 실제 고객·현장 객체 인스턴스나 전체 생산 스키마가 아니다.

실물·관측 / 공간·이동 / 기관·업무 / 운영안·실행 / 규칙·적용성 / 모델·증거 / 대본·검수 / 사용자 업무·비용·도입을 구분한다.

기본 관계: 원문 조항 → 규칙 후보 → 적용 검수 → 업무 → 실행 이벤트 → 발견사항 → 운영안 수정 → 대본 단계. 추가 관계: 실제 최근 업무 → 파일럿 사례 → 비교 프로토콜 → 실제 StudyRun → 시간·품질 관측 → 효용 판정. SitePackage의 변경은 ChangeImpact를 통해 관련 모델·대본·검수 상태에 전달한다.

WorkTimeEntry는 실제 사람의 시간을 기록한다. simulationTime과 합치지 않는다. StudyProtocol은 계획이며 StudyRun만 실제 조사 활동이다. 작성자·구매자·가상 현장 인력을 같은 Persona로 묶지 않는다. QualificationVector는 독립 축으로 유지하며 user preference가 physics validation으로 추론되지 않는다.

타입 검사·RDF 파싱은 개념 관계가 읽힌다는 검사일 뿐 원문 해석·현실 데이터 진위·현장 정확도 검증이 아니다. 승인에는 실제 주체·권한·범위·원시근거가 필요하다.
