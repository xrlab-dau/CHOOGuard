# CHOOGuard 무료 우선 에셋 카탈로그

기준일: 2026-09-19 · PRD v10 §17.4 보완 후보 · GitHub/기존 PRD 미변경

## 결론

소방·구급·경찰 차량은 RGS_Dev, 일반 배경·철도는 Kenney, 인물은 CharCrafter 무료 샘플과 Quaternius, 한국 소화기는 Poly Haven을 먼저 비교한다. 소방·경찰 제복, 한국 긴급차량 정확한 외형, 들것 공동운반 애니메이션은 추가 제작·검사가 필요하다.

아래 25개는 무료 개별 모델·무료 팩·무료판·라이브러리/서비스의 **후보 기록**이다. 신규 원본 25개 확보나 완성된 시뮬레이터 25개를 뜻하지 않는다. 제작자 주장, 무료 다운로드 화면, 파일 실제 검사, Unity 실행을 구분한다. 이번 신규 원본 취득 0개, Unity 임포트·물리 검증 미실행. 기존 KTX 아카이브 바이트·해시만 다시 확인했다.

## 무료 취득 시 주의할 구분

Kenney는 개별 페이지의 무료 Download 경로를 이용한다. All-in-1은 별도 상품이다. itch.io의 이름 지정 결제는 `No thanks, just take me to the downloads`로 무료 경로를 선택한다. Quaternius Standard와 Pro/Source를 구분한다. 에셋을 취득한 후 원본 판본·조건도 함께 기록한다.

폴리곤/프리팹 수는 별도 명시가 없으면 플랫폼이나 제작자의 표시값이며 직접 파일 검사 결과가 아니다. 검색자료의 개수와 원문 페이지 수치가 다른 항목은 정확한 ZIP을 받은 뒤 확인한다.
