# 승무원 열차점검 튜토리얼 · #281

## 진입과 분량

시작 화면 → **튜토리얼 모드 → 승무원 열차점검 → 안내 시작**.

튜토리얼은 CrewTrainTutorial 씬에서 오프라인으로 진행한다. 일반 근무의 사건 생성과 JEV 판정을 불러오지 않는다. 2분 30초~5분을 목표로 구성하며, 시간을 채우는 대기·왕복·재시험과 시간 초과 실패는 없다.

## 2026-10-12 원영상 업무에 맞춘 수정

무전기는 근무 전 전원·배터리 확인과 이후 출발 보류/완료 보고에 사용한다. **비상통화 인터폰 시험은 객실의 기존 인터폰에서 수행한다.** 방송이 끝난 뒤 호출 버튼을 누르면 호출음 → 점검 통화 → 상대 응답 → 통화 종료 순으로 진행한다. 휴대 무전기의 전원·송수신 상태를 인터폰 시험 결과로 사용하지 않는다.

인터폰 패널에 조작 전부터 테두리 표식을 표시한다. 작은 호출 버튼의 정확한 픽셀만 맞추지 않아도 패널 안을 바라보면 E로 호출할 수 있다. 판정은 실제 패널에 부착된 고체 표면에서만 이루어지며 주변 벽이나 차폐물을 건너뛰지 않는다.

인터폰 위치 점은 실제 패널 표면에 붙인다. 상호작용 범위의 월드 AABB를 표시하던 방식은 회전된 패널 옆 유리까지 테두리가 번지는 문제가 있어, 패널 자체의 방향·너비·높이를 투영하도록 바꿨다. 이름은 위치 점 옆에 별도로 표시한다.

간략화된 충돌체는 보이는 인터폰보다 앞의 다른 평면에 있어, 그 충돌체의 레이 교차를 장비 위치로 사용하면 한 시점에서만 겹쳐 보인다. 실제 렌더 메시 `Car02_T2 2car_08_T2-1_in_002`의 표면을 기준으로 패널 위치와 방향을 측정하고 같은 메시 변환에 연결한다. 구체적인 위치 점과 E 판정이 실제 패널의 깊이를 공유한다. 가까운 시점과 측면 시점을 전달용 EXE에서도 확인한다.


객실 점검은 객실 앞쪽과 중앙으로 직접 이동하며 수행한다. 각 구역에서 좌석 외관 → 창가와 주변 설비 → 상부 선반을 표식에 따라 관찰한다. 한 곳만 바라보거나 E/Enter만 연타해 전체 점검을 완료할 수 없다. 순회하며 차량 이상을 살피는 영상의 업무를 짧은 객실 구역에서 체험하도록 구성했다.

영상의 더운 객실 조절 업무도 포함한다. 냉난방 제어반에서 온도 설정을 낮추고 변경 표시를 확인한다. 영상에서 확인되지 않은 표준 온도나 유지보수 기준치를 만들지 않으며, 실제 객실 온도가 즉시 내려간 것으로 처리하지 않는다.

안전 비품과 첫 출입문 이상 대응은 유지한다. 문 주변의 짐은 대화에서 합의한 교육용 사례다. 소화기 위치·외관 확인은 추가 안전 장비 항목이다. 객실 좌석/창가/선반 관찰 순서는 영상의 일반적인 이상 점검 업무를 안내하기 위한 구성이고, 영상에 해당 세 항목이 공식 체크리스트로 제시됐다고 주장하지 않는다.

## 전체 흐름

### 2026-10-13 방송장치와 완료 무전 보정

천장 스피커는 본게임과 같은 프리팹이지만 튜토리얼용으로 추가한 배치다. 원래 자율모드의 해당 객실 위치에 이미 있었다고 설명하지 않는다. 기존 높이에서는 공중에 떠 있어 실제 열차 천장 메시 표면을 확인해 하우징의 윗면이 천장에 붙도록 옮겼다. 원본 자율모드 씬은 변경하지 않는다.

무전의 ‘보고’ 묶음과 단일 완료 보고 문장이 같은 방향에 표시되는데 메뉴 전환 시 선택 방향을 초기화하면, 마우스를 그대로 두고 Q를 놓을 때 전송이 취소됐다. 튜토리얼의 ‘보고’ 묶음을 열 때 선택 방향을 유지한다. 문장 위치가 달라지는 ‘요청 · 설비’는 기존처럼 다시 선택한다. 문장이 선택된 상태에서 Q를 놓으면 전송하며 선택 없이 취소하는 경우에는 이유를 표시한다. 본게임 RadioWheel의 기본 초기화 동작은 유지한다.

무전기 준비 → 방송 출력 → **비상통화 인터폰 시험** → 소화기 → **객실 앞쪽·중앙 점검 → 냉방 설정 조절** → 첫 출입문 점검에서 짐 걸림 확인 → 출발 보류 → 문 개방 → 정리 요청 → 문 닫힘 확인 → 완료 보고. 총 13단계다.

구급 비품은 영상에서 개인 가방에 준비하는 물품이다. 객실 고정 비품처럼 보여 주던 구급 가방 배치·위치 점검 단계·음성은 제거했다.

문과 짐은 실제 모델이 연속해서 움직이고, 해당 결과를 바라본 뒤 확인 완료된다. 별도 복습 시험은 없다.

## 조작

- WASD 이동 / 마우스 시점.
- E: 표시된 실제 장비를 조준해 점검·조작 시작.
- 객실 점검 중에는 좌석·창가·선반의 표식을 차례로 바라본다.
- Q를 누른 채 마우스로 무전 문장을 고르고 Q를 떼면 전송한다. 기존 RadioWheel을 재사용한다. 견학은 문장을 바로 선택하고, 표준·실전은 묶음을 좌클릭으로 열고 우클릭으로 돌아간다. Q만 눌렀다가 떼면 전송하지 않는다.
- Enter: 반응과 관찰이 끝난 뒤 결과 확인.
- R: 안내 다시 듣기 / V: 교육·교신 음성 켜기·끄기.
- Esc: 음성·동작까지 일시정지. 재시작/복귀 가능.
