# 화재 튜토리얼 팀원 플레이 리뷰

마지막 로컬 학습 개선14의 화재 튜토리얼을 공용 연습 메뉴에 연결한 검수 버전입니다. PR을 merge하지 않고 실행 파일로 플레이하거나 PR 브랜치를 Unity에서 열어 확인할 수 있습니다.

## Windows 실행

1. PR 본문의 **Windows 실행 파일** 링크에서 ZIP을 받습니다.
2. ZIP을 폴더째 압축 해제합니다. `Game` 폴더 안의 파일을 따로 옮기지 않습니다.
3. `Play-Fire-Tutorial.cmd`를 실행합니다. Unity Editor, Unity Hub, Node, AI 계정은 필요하지 않습니다.
4. 첫 메뉴에서 **비상상황 연습 → 역무원 화재대응**을 선택합니다.
5. 준비가 끝나면 **계속**을 눌러 시작합니다. 첫 실행은 역사와 셰이더 준비 때문에 시간이 걸릴 수 있습니다.

실행 파일은 Windows x64용입니다. 다른 OS에서는 아래 Unity 실행 방법을 사용합니다. 이 버전의 초기 화면은 기존 기차 튜토리얼 메뉴를 유지합니다.

## 조작

| 행동 | 입력 |
|---|---|
| 이동·시점 | WASD·마우스 |
| 승객에게 위험 안내·소방대에 상황 전달 | 가까이 가서 대상을 보고 E |
| 무전 | Q를 누른 채 묶음 선택 → 좌클릭으로 하위 메뉴 → 메시지를 골라 Q를 놓아 전송 |
| 소화기 들기·내려놓기 | 대상을 보고 F·G |
| 안전핀·노즐 준비 | 부품 조준 → 좌클릭 유지 → 휠 위로 또는 표시 방향 드래그 → 준비되면 놓기 |
| 분사·중지 | 준비된 레버를 좌클릭한 채 화점 아래쪽 조준·좌클릭 놓기 |
| 다음 자막 | Enter |
| 일시정지·자세한 설명·복습·대화 기록 | Esc |

화면에 표시되는 현재 목표와 조작 순서를 우선합니다. 노즐 방향과 실제 약제 잔량이 반영되며, 약제를 다시 채우는 기능은 없습니다.

## 확인할 플레이 흐름

- **정상 대응:** 가까운 승객 안내 → 위치 보고·지원 요청 → 기존 비치 소화기 확보 → 핀·노즐 준비 → 퇴로를 확보한 초기소화 → 결과 보고 → 소방대에 상황 전달 → 수행 결과 확인.
- **중단·철수:** 초기소화를 중단하고 잔류 화재를 보고한 뒤 소방대에 전달합니다. 사용하지 않은 소화기를 사용한 것으로 기록하지 않아야 합니다.
- **학습 UI:** 자막을 읽을 시간, Enter로 다음 자막 보기, Q 메뉴를 가리지 않는 안내, Esc의 설명·장비 복습·무전 복습·대화 기록을 확인합니다.
- **다시 플레이:** 처음부터 다시 시작과 연습 목록 복귀를 확인합니다. 연습 목록에서 기차 튜토리얼·심정지 연습으로도 이동할 수 있어야 합니다.
- **성능:** 처음 사람과 대화할 때, 화재 방향을 볼 때, 소방대에 전달할 때를 포함해 이동과 조작 전반의 끊김을 확인합니다.

## 리뷰 작성 양식

PR의 일반 코멘트에 아래 내용을 남겨 주세요. 코드 위치가 분명하면 해당 줄에 리뷰를 달아도 됩니다.

```text
플레이한 ZIP 버전/manifest.json의 sourceCommit:
PC: CPU / GPU / RAM / 화면 해상도:
완료 여부: 정상 대응 / 중단·철수 / 완료하지 못함
막힌 단계와 재현 순서:
화면에 표시된 안내와 내가 시도한 조작:
프레임이 크게 떨어진 위치·행동:
자막·설명·복습에서 이해하기 어려웠던 부분:
스크린샷 또는 Player.log 첨부(가능하면):
```

`Player.log`는 압축을 푼 폴더에 생성됩니다. 로그를 올리기 전에 로컬 경로 등 공유하고 싶지 않은 내용을 확인해 주세요.

## Unity에서 소스 확인

Unity **6000.3.23f1**로 PR 브랜치를 열고 Git LFS 파일을 받아야 합니다. `TrainDepartureDemo` 씬에서 **비상상황 연습 → 역무원 화재대응**으로 진입합니다. `StationFireTutorial` 씬을 직접 실행해도 역사 씬을 추가로 불러옵니다.

Windows 검수 빌드를 다시 만들 때는 `CG_FIRE_PLAYER`를 출력 폴더로 지정하고 `ChooGuard.Editor.StationFireTutorialSceneBuilder.BuildReviewPlayer`를 실행합니다. 기존 역사 맵을 다시 생성하는 `Build()`는 검수 빌드에 필요하지 않습니다.

## 현재 범위와 의존 관계

- 이 PR은 공유 연습 메뉴 **#333**을 기반으로 합니다. #333의 기차·심정지 흐름을 유지하면서 별도 화재 튜토리얼 씬을 연결합니다.
- **#334**의 자율모드 기반 화재 연습 초안과는 다른 구현입니다. 두 구현의 통합 여부는 팀 리뷰에서 결정하며 이 PR이 다른 PR을 자동으로 merge하거나 닫지 않습니다.
- 이 튜토리얼은 정해진 교육 상황입니다. 자율모드 종합 점수·학습 성취도 평가의 완성을 뜻하지 않습니다.
- 현행 기관 SOP의 인증이나 실제 출동 시간·실측 치수를 재현한 것이 아닙니다. 세부 출처와 모델링 범위는 [구현 문서](STATION-FIRE-TUTORIAL.md)를 참고합니다.
- 학교 PC와 초행 사용자의 플레이 검수는 아직 필요합니다. 모든 환경에서 일정 FPS나 프레임 드랍 0을 보장하지 않습니다.
- 복습 탭은 읽기 전용입니다. 특정 단계부터 다시 수행하는 부분 재시작은 포함하지 않습니다.
