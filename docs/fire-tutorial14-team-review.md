# 화재 튜토리얼 14번 — 팀원 플레이 리뷰

이 검수본은 마지막으로 확인한 **로컬 화재 튜토리얼 14번**입니다. 최신 열차 시작 화면이나 별도 비상상황 연습 메뉴를 합친 버전이 아닙니다. PR #336의 병합 전에 동일한 학습 흐름을 플레이하고 의견을 남기는 용도입니다.

## 실행

1. PR #336에 연결된 `CHOOGuard-FireTutorial14-Windows-x64.zip`을 내려받고 **전체 압축을 풉니다**.
2. 쓰기 가능한 폴더에서 `Play-Fire-Tutorial.cmd`를 실행합니다. `Game` 폴더 전체가 필요하며 EXE만 옮기면 실행되지 않습니다.
3. **플레이 시작 → 튜토리얼 → 역무원 화재대응**으로 들어갑니다.

Windows x64용이며 Unity Editor, Node.js, Unity 라이선스, AI 계정 로그인이 필요하지 않습니다. 실행 스크립트는 외부 AI 호출을 비활성화하고 기존 14번과 같은 1280×720 창·Direct3D 11 설정을 사용합니다. 첫 실행과 역사 진입에는 로딩 시간이 걸릴 수 있습니다. 종료는 Esc 메뉴 또는 창 닫기를 사용합니다. 실행 로그는 압축을 푼 폴더의 `Player.log`에 기록됩니다.

## 조작과 확인할 흐름

- WASD·마우스로 이동하고 바라봅니다. 가까운 승객을 보고 E로 위험과 열린 통로 방향을 안내합니다.
- Q를 누른 채 무전 방향을 선택하고 좌클릭으로 묶음을 연 뒤 Q를 놓아 보고합니다.
- 원래 비치된 소화기를 F로 들고 G로 내려놓습니다. 핀과 노즐을 조준하고 좌클릭 드래그 또는 휠 위로 준비합니다. 준비된 레버는 좌클릭을 누르는 동안 분사합니다.
- 자막은 읽은 뒤 Enter로 넘길 수 있습니다. 안내·보고·장비 조작을 마친 뒤 소방대 가까이에서 E로 관찰한 상황을 전달합니다.
- 정상 초기소화 외에 중단·철수 보고, Esc 일시정지·복귀, 재시작도 확인해 주세요. 세부 입력과 학습 경계는 함께 제공한 `STATION-FIRE-TUTORIAL.md`를 참고하세요.

## 출처와 검증 범위

- 학습 소스는 `8aed3d05e04f713205dfa7273adbbd4cd8ed6afb`입니다. 기반 커밋은 `df652f26b8a009964593b49ac09adac012f202b2`이며 이후 팀원 메뉴 변경을 포함하지 않습니다. 이 안내 문서만 추가해 검수 브랜치로 공유합니다.
- 실행 파일은 새로 통합·재빌드한 파일이 아니라 **기존 14번 Windows 플레이어의 런타임 파일을 그대로 복사**한 것입니다. 기존 로컬 실행에 사용한 포커스 처리용 DLL도 포함합니다. 따라서 소스 커밋만 새로 빌드한 바이너리와 바이트가 같다는 뜻은 아닙니다. 파일별 SHA-256과 출처는 `manifest.json`으로 확인할 수 있습니다.
- 2026-11-16 기록: 실제 Windows 플레이어 검사 138개 통과, 별도 백그라운드 정상 진행 검사 50개 통과. 화면 28개·글자 항목 198개에서 잘림 문제 0개였습니다. 이번 패키징에서 이 검사 전체를 새로 수행했다고 주장하지 않습니다.
- 당시 유효 렌더 프레임 11,502개 중 50ms 초과 3개, 최대 741.527ms였습니다. 다른 게임이 실행 중인 환경의 관측값이며 학교 PC에서 프레임 저하가 없다는 보장은 아닙니다. 초행 사용자 사용감은 이번 리뷰 대상입니다.
- 현재 `develop`의 시작 흐름과 빌드 씬 목록이 달라 병합 충돌을 별도로 해결해야 합니다. **동일한 14번 플레이 검수를 위한 Draft PR**이며 그대로 병합할 준비가 끝났다는 의미는 아닙니다.
- 장비·무전 복습은 읽기 전용입니다. 부분 단계 재시작과 자율모드 종합 점수·성취도 기능은 포함하지 않습니다.
