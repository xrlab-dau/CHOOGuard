# 화재 튜토리얼 14번 — PR 소스로 플레이 리뷰

팀원들은 **PR #336의 브랜치를 체크아웃한 뒤 Unity에서 직접 실행**하면 됩니다. 우리가 다른 팀원의 PR을 가져와 검수한 방식과 같습니다. 실행용 ZIP, 별도 실행기, Node.js, 로컬 패치 DLL은 필요하지 않습니다.

## PR 가져오기

작업 중인 변경을 먼저 보존한 뒤 기존 CHOOGuard 저장소에서 실행합니다.

```sh
gh pr checkout 336
git lfs pull --include="Assets/**"
```

GitHub CLI가 없다면 아래 Git 명령으로 같은 PR을 가져올 수 있습니다.

```sh
git fetch origin pull/336/head:review/fire-tutorial14
git switch review/fire-tutorial14
git lfs pull --include="Assets/**"
```

`origin`이 CHOOGuard 저장소인 기존 클론 기준입니다. 다른 클론에서 새로 가져오는 경우에도 Git LFS로 원본 에셋을 동기화해야 합니다. LFS 포인터만 있는 상태에서는 역사·열차 메시를 정상적으로 가져올 수 없습니다.

## Unity에서 실행

1. Unity Hub에서 **방금 체크아웃한 저장소 루트**를 엽니다. Editor 버전은 `ProjectSettings/ProjectVersion.txt`와 같은 **6000.3.23f1**입니다. 평소 다른 PR을 실행할 때와 같은 Unity Editor·라이선스가 필요합니다.
2. 최초 가져오기와 스크립트 컴파일이 끝나면 상단 메뉴 **ChooGuard → Review → Play fire tutorial 14**를 선택합니다.
3. 등록된 `StationFireTutorial.unity`로 Play 모드가 시작됩니다. 역사 준비가 끝나면 안내를 읽고 실습을 시작합니다. 별도 게임 파일을 빌드하거나 다운로드하지 않습니다.
4. Unity의 Play 버튼으로 중지합니다. 검수 메뉴는 작업 중이던 씬을 저장·재생성하지 않으며 종료 후 기존 Play 시작 씬 설정을 복원합니다.

현재 시작 메뉴 흐름도 확인하려면 `Assets/ChooGuard/Scenes/TrainDepartureDemo.unity`를 열고 Play → **훈련 선택 → 화재 튜토리얼**로 들어갑니다. 종료 화면의 **훈련 선택**을 누르면 같은 메뉴로 돌아옵니다. **비상상황 연습 → 화재 → 맞이방 작은 불**은 별도의 사건 연습입니다.

**`Build station fire tutorial`은 에셋을 만드는 개발용 메뉴입니다. 플레이 리뷰에서는 실행하지 마세요.** 필요한 씬·장비·카탈로그·Build Settings는 PR에 들어 있습니다. 대용량 역사 때문에 최초 가져오기와 첫 진입에 시간이 걸릴 수 있습니다. 화재 학습은 외부 AI 응답이나 API 키 없이 진행합니다.

## 조작과 리뷰

- WASD·마우스 이동과 조준, 가까운 인물을 보고 E로 안내·상황 전달
- Q를 누른 채 무전 방향 선택, 좌클릭으로 묶음 열기, Q를 놓아 보고
- F로 원래 비치된 소화기 들기, G로 내려놓기
- 핀·노즐을 조준하고 좌클릭 드래그 또는 휠 위로 준비, 준비된 레버는 좌클릭을 누르는 동안 분사
- Enter로 자막 넘기기, Esc로 일시정지·복귀·재시작·훈련 선택

다음 행동을 이해할 수 있는지, 자막이 시야를 가리거나 잘리는지, 실제 장비 조작과 무전 전환이 자연스러운지 확인해 주세요. 화재·첫 대화·인계뿐 아니라 이동과 일시정지 등 전체 흐름의 끊김도 리뷰 대상입니다. 정상 초기소화와 중단·철수 보고를 구분해 확인해 주세요.
