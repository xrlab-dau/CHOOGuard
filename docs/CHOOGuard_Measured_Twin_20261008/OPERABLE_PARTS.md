# 부산역 공식 소스의 실제 부품 분리 · 2026-10-08

공식 SKP의 본동/맞이부와 명명된 순환 설비를 실제 메시와 편집 가능한 부모/자식 계층으로 내보냈다. 주변 건물과 기차의 반복 노드는 제외했다. 임의 모델이나 임의 설치 위치는 만들지 않았다. 현장 실측 정확도와 현재 부산역 전체 내부의 완성도를 인증한 결과는 아니다.

소스 문짝 계열은 실제 경계가 폭 약 0.9/0.9625/0.885m, 높이 2.1m의 얇은 패널이며 소스 피벗이 폭 한쪽 끝에 있다. 큰 `문A_역#`는 폭 7–8m/높이 약6m의 상위 조립체다. 구조 분석은 애니메이션 연결 대상을 구별하는 근거이며 실제 힌지 축/최대 개방각/현재 설치 상태에 대한 실측 인증은 아니다.

## 위치 · 재질 검증

경량 FBX를 Blender에 새로 재수입해 3,648개 소스 ID/부모 관계, 1,686개 메시의 삼각형과 UV loop 수를 전부 대조했다. 소스 월드 피벗 최대 전송 오차는 0.0001113m, AABB 좌표 최대 오차는 0.0000916m였다. 원본과 재수입의 328,548개 UV loop 값은 오차 0이었고 재질 슬롯 이름과 면별 재질 인덱스도 전부 같았다. 원본 .blend의 정점/UV/인덱스/재질 배열 SHA256은 기존 추출 명세와 전부 일치했다.

이 오차는 파일 변환 과정의 소스 보존 검사다. 실제 부산역과의 오차가 아니다. 공식 원본의 예전 단위와 좌표를 보존한 것이 현재 현장의 독립 2cm 실측 검증을 대신하지 않는다.

전체 배경 FBX에는 11개 메시 인스턴스에서 재수입 후 삼각형 수가 1–4개씩 줄었다. `qa.json.differing_source_meshes`에 정확한 소스 ID와 전후 수를 보존했다. 따라서 전체 FBX의 모든 면이 동일하다고 인증하지 않는다. 이 차이는 경량 조작 후보에는 포함되지 않았으며 후보 FBX는 면 수/UV/재질 검사를 통과했다. 전체 원본 .blend의 실제 배열과 계층은 계속 보존된다.

## Unity로 연결할 때

기존 공식 배치 모델의 실제 가져오기 프레임을 먼저 대조한다. 16.2° 등 다른 내부 구조 보정 값을 이 FBX에 적용하지 않는다. 소스 좌표는 미터/Z up이며 기본 Blender FBX `-Z forward/Y up`를 사용했다. Unity의 FBX 단위/축 처리까지 포함해 기존 배치 모델의 실제 정점을 대조한 뒤 같은 면만 제거하고 분리 노드를 활성화해야 한다. 중복 렌더링이나 새 임의 설치를 만들지 않는다.

Root가 기존 모델에서 회수한 소스 미터 → Unity 월드 후보 행렬은 다음과 같다. 이는 기존 모델 좌표의 정합이며 현장 실측 좌표 인증이 아니다. 실제 도입 코드는 독립 정점 일치 검사로 확인해야 한다.

```text
[ 0.99997093,  0.00762750, 0, -41.3421974 ]
[ 0,           0,          1,   0         ]
[-0.00762750,  0.99997086, 0, -19.3077888 ]
[ 0,           0,          0,   1         ]
```

재질은 `materials.json`의 정확한 소스 이름과 파일 해시로 재사용/매핑한다. 원본 텍스처가 shader color에 직접 연결된 경우 색 배율을 1로 내보내 원본 픽셀을 유지한다. 텍스처가 없는 경우 원본 Blender 선형 색과 실제 Principled Alpha를 사용한다. 흰색 임시 재질이나 분홍색 기본 fallback으로 완료 처리하지 않는다.

현재 범위는 실제 소스 부품 파일과 검증·정합 입력을 제공하는 작업이다. Unity 생산 씬 도입/배치 메시 절단/상호작용 연결 여부는 [구현 보고서](IMPLEMENTATION_REPORT.md)의 현재 실행 결과를 따른다. 원본 자체에 없는 최신 내부 설비, 익명 조립체의 확정 의미, 실제 작동 범위와 독립 현장 정확도는 별도로 확인해야 한다.

재현 도구: `workers/twin/operable_parts.py`의 `inventory`, `export`, `verify`, `verify_candidates`; `semantic/fingerprints-script.py`, `materials-script.py`, `material-uv-qa-script.py`는 유지된 실제 원본 데이터만 읽어 별도 검증/명세를 생성한다.
