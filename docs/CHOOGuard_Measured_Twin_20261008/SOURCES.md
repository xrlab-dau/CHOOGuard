## 기존 자료의 실재 감사와 중복 재사용

[existing-evidence-audit.json](../../asset-library/research-public/2026-10-08/measured-twin/existing-evidence-audit.json)은 현재 보존된 실내 관찰 명세·기존 실내 specs·2026-10-05 에스컬레이터 receipts·공식 원본 acquisition receipt를 대상으로 한다.

- 감사 문서 **149개**, 중복을 제거한 원자료 경로 참조 **122개** 중 실제 파일 **29개**, 누락 **93개**.
- 기존 `asset-library/research-public/2026-09-23/busan-sinmajibang/` 경로는 현재 존재하지 않는다. 남아 있는 receipt나 설명은 해당 원본 이미지의 파일 존재를 증명하지 않는다. 신규 취득 파일은 새 경로로 기록하며 누락된 기존 경로를 존재한다고 표시하지 않는다.
- 현재 에스컬레이터 조사 폴더의 실제 영상 파일 **152개**, 해결된 원본 video ID **97개**를 해시와 함께 재사용 목록으로 작성했다. 일부 컷의 원본 ID·촬영일은 추가 확인 대상이며 원본 제목을 경계 검증으로 대신하지 않는다.
- 같은 해시의 파일은 중복 그룹으로 기록했다. 같은 source video에서 나온 서로 다른 컷은 해시가 달라도 같은 관찰 그룹이다.
- 감사 범위 밖의 모든 자산이 검증됐다는 의미는 아니다. 실제 Unity 배치·전체 객체 수는 별도 전수 감사와 연결한다.

## 철도 부산역과 도시철도의 구분

[scope-exclusions.json](../../asset-library/research-public/2026-10-08/measured-twin/scope-exclusions.json)에 잘못 섞이기 쉬운 후보를 기록했다.

- Aside 검색에서 확인한 2026 Busan Metro 투어 `KK_DgLstdX0`와 부산1호선 안내방송 `d4J3y8_EMiA`는 철도 부산역 건물의 실내 기하 자료로 채택하지 않는다.
- 기존 BISCO 부산역 지하상가·도시철도 지도와 BVE 지하철 시뮬레이터는 KTX 역사 평면도가 아니다.
- 원본 영상에 철도 역사·지하철·플랫폼·열차가 함께 있으면 원본 전체 대신 실제 확인한 실내 구간만 연결한다.
- 철도 역사 인근의 도서관·문화시설·유라시아플랫폼과 건물 내부 시설을 혼동하지 않는다. 층·출입구·연속 경로가 확인되지 않은 공간은 위치 미확인이다.

## 아직 부족한 자료

[missing-coverage.json](../../asset-library/research-public/2026-10-08/measured-twin/missing-coverage.json)에 구역별로 현재 참조와 다음 관측을 적었다. 모든 구역에서 새 동일 시점 촬영, 현장 좌표계, 정합용 실측점, **분리된 독립 검증점**이 없다. 따라서 2cm 또는 100%에 가까운 완전성을 통과한 구역은 현재 없다.

필요한 작업은 [CAPTURE_GUIDE.md](CAPTURE_GUIDE.md)의 구역별 연속 촬영과 객체·가동부 사진, 기준점과 독립 치수의 실측이다. 공개 영상의 작은 구간을 실제 로컬 복원해 메시를 생성했으며 결과는 참조 복원으로 표시한다. [실행 결과](../../workers/twin/evidence/reference-pilot-final.json) 향후 기준 시점이 다른 자료가 더 취득되면 촬영 시점과 실제 변경 상태부터 대조한다.
