# 부산역 동일 시점 촬영·실측 안내

이 안내는 부산역 **철도 역사 건물**의 새 기준 시점을 확보하기 위한 현장 작업 절차다. 현재 내려받은 공개 사진·영상은 과거 외관·설비·점포의 참조 자료이며, 새 현장 시점이나 2cm 오차 검증을 대신하지 않는다. 촬영·측량이 실제 확보되기 전까지 해당 구역과 객체는 미검증으로 유지한다.

## 촬영 시점과 공간 범위

- 작업 시작·종료를 시간대가 있는 ISO 8601 시각으로 기록하고 `capture_epoch.id` 하나에 묶는다. 서로 다른 날의 자료는 날짜가 확인돼도 자동으로 합치지 않는다. 설비·점포·물품이 변경되지 않았는지 확인한 뒤 같은 기준 시점으로 채택한다.
- 조사 대상은 철도 부산역의 공개 접근 가능한 층별 공간, 점포 접근부, 실내 층간 연결과 운영 설비다. 도시철도 부산역과 지하 상가는 별도 장소다. 외부 출입구 연결은 좌표 정합용으로 관측하고 실내 비상상황 영역과 구분한다.
- 현장 작업 중 공개 접근 범위와 현장 운영 안내를 따른다. 실제 비상정지·차단·화재 설비는 촬영을 위해 작동시키지 않는다. 일상 운행과 담당자의 허용된 시연으로 기능을 관찰한다. 내부를 보지 못한 문·기계실은 미촬영으로 기록한다.

## 구역별 누락을 먼저 기록

| 조사 구역 | 연속 경로 사진·영상 | 별도로 필요한 정지 사진·측정 |
|---|---|---|
| 1F 공용·출입구 | 출입구마다 안팎 연결, 공용 통로 왕복, 계단·상하행 연결 | 문 개구부·문짝·잠금·손잡이·버튼, 기둥 모서리, 안내도, 대기 물품과 실제 설치점 |
| 1F 점포·서비스 | 점포 전면과 공개 내부, 공용부와의 연결 | 점포 경계·문·진열대·카운터·설비; 접근 불가 후면은 가림 기록 |
| 2F 본관 대합실 | 벽면을 따르는 순환 경로와 가로질러 걷는 교차 경로 | 매표·키오스크·ATM·AED·소화전·방송·안내·게시판, 바닥 기준점과 천장 높이 |
| 2F 박스·연결부 | 본관에서 연결부를 통과하는 왕복 경로 | 코너, 단차, 유리와 난간, 연결부 양쪽 공통 기준점, 모든 실내 출입문 |
| 2F 점포·편의 | 전면 전체와 공개 내부, 실제 물품 상태 | 간판·점포 경계·고정 집기·조작부와 설치 치수 |
| 3F 식당·공용부 | 층간 연결의 양쪽에서 시작하는 순환 경로 | 점포 경계, 천장·계단·난간, 실제 조작 설비; 4F 연결 여부를 별도 확인 |
| 층간 연결 전부 | 승강기 층별 앞, 객실, 계단과 에스컬레이터의 양쪽 끝 | 호기/층 표시·제조 명판·버튼·통화·문·발판·손잡이·정지 버튼·방향 표시 |
| 실내 승강장 접근부 | 개찰/출입문 안쪽까지의 접근과 안내·바닥 연결 | 경계 위치와 층간 설비의 실제 호기 연결; 승강장 영상 구간은 실내 등록과 분리 |
| 가림·미확인 공간 | 가림의 양쪽과 대체 시선 | 관측되지 않은 부분, 재촬영 필요 여부, 미검증 사유 |

과거 등록부의 승강기·에스컬레이터 개수는 조사 시작 목록으로 활용한다. 새 현장에서 실제 존재와 위치·호기·연결 층을 대조하며, 이름이나 개수 일치만으로 대응 객체를 확정하지 않는다.

## 카메라와 촬영 경로

1. 사진의 원본 해상도·EXIF와 영상 원본을 유지한다. 사용 기기·렌즈·초점거리·해상도·안정화 설정·촬영 방향을 기록한다. 촬영 중 디지털 줌과 임의 크롭을 바꾸지 않는다. 노출·초점 변화가 큰 구간은 별도로 표시한다.
2. 구역을 작은 겹치는 블록으로 나눈다. 같은 표면을 위치가 다른 카메라에서 반복 관측한다. **제자리 회전 영상만으로 깊이를 복원하지 않는다.** 통로를 왕복하고 교차 경로·루프를 추가한다.
3. 사진의 약 70–80% 겹침을 시작 기준으로 삼되, 정합된 카메라와 실제 표면 관측을 보고 재촬영한다. 평평한 벽·바닥·반복 무늬에만 의존하지 않고 고유한 기둥·표지·고정 모서리를 함께 담는다. 이 겹침 수치는 프로젝트 촬영 기본값이며 정확도 보장이 아니다.
4. 천장과 낮은 조작부는 수평 눈높이 촬영과 구분해 위·아래 각도 사진을 추가한다. 반사 유리·금속은 여러 시선으로 관측하고 불투명 고정 기준점을 함께 담는다.
5. 객체마다 전체 형상·주변 위치 관계·설치점·가동부 경계·조작부 근접을 촬영한다. 문은 문틀과 문짝을, 버튼은 패널과 실제 움직이는 부분을, 승강기는 각 층의 문과 같은 객실 연결을 각각 기록한다.
6. 영상 프레임은 추출 시 원본 ID와 원본 시간(초/PTS)을 보존한다. 동일 영상의 컷·프레임·업스케일은 같은 `derived_from` 그룹이다. 사람·차량·작동하는 발판은 정적 복원용 입력에서 마스크/제외하고 기능 관찰 기록은 따로 보존한다.

## 실측 기준점과 독립 검증점

**0.02m는 합격 목표다. 사진 정합 오차·모델 단위·예상 층고를 실측값으로 입력하지 않는다.**

- 좌표계를 먼저 정한다. `coordinate_frame.id`, metres 단위, 오른손/왼손, 축의 방향, 기준 원점, Unity로의 변환을 기록한다. 기존 Unity 좌표를 현장 좌표로 간주하지 않는다.
- 고정 구조의 식별 가능한 모서리 또는 안정적으로 재관측할 수 있는 표식을 사용한다. 위치 기준은 막연한 물체 중심 대신 특정 설치 모서리/회전축/바닥 접점으로 정하고 사진에 표시한다.
- 각 블록에 수평·수직으로 분산된 정합점(`role: fit`)과 **분리한 검증점(`role: holdout`)**을 마련한다. 시작 기본값은 정합점 6개 이상, 독립 검증점 8개 이상이다. 한 평면/좁은 모서리에 집중된 배치는 피하고 층간 연결에도 공통 정합점을 둔다. 개수만으로 2cm 합격을 보장하지 않는다.
- 좌표·거리·높이는 사용한 측정 방법, 장비 정밀도/교정 근거, 반복 측정, 관측 시각, 측정 불확실성과 함께 남긴다. 2cm 목표 판정을 위해 5mm 수준 이하의 불확실성을 계획 기본값으로 삼고 실제 보고값을 기록한다. 스마트폰 GPS, 촬영자 눈높이, 안내도 축척 가정은 실내 2cm 검증 수단이 아니다.
- 정합점은 축척·회전·이동 추정에만 사용한다. 검증점과 독립 치수는 보정·모델 튜닝에 사용하지 않는다. 검증 결과를 보고 모델을 수정했다면 별도 검증점을 다시 측정/보류하고 검증 회차를 새로 만든다.
- 객체별 핵심 치수(문 개구부, 버튼·정지 버튼 높이, 승강기 문과 객실 치수, 계단 단차, 난간·통로 폭)를 독립 측정한다. 여러 사진에서 같은 치수를 추론한 값은 독립 실측으로 분류하지 않는다.
- 합격 판단에는 전체 평균 외에 지점별 3차원 위치 잔차, 최대 오차, 치수 오차, 구역별 누락과 측정 불확실성을 함께 보고한다. 불확실성이 크거나 검증점이 없는 객체는 `unverified`로 유지한다.

## 제출 데이터 계약

`workers/twin` intake의 계약에 맞춰 다음 항목을 기록한다. 모든 시각에는 시간대를 포함한다. 데이터가 없는 필드는 값을 지어내지 않고 누락/미검증으로 남긴다.

```json
{
  "capture_epoch": {"id": "FIELD-EPOCH-ID", "started_at": "ISO-8601", "ended_at": "ISO-8601"},
  "coordinate_frame": {"id": "SITE-FRAME-ID", "units": "metres", "handedness": "MEASURED", "axes": "DOCUMENTED", "unity_from_site": "MEASURED-TRANSFORM"},
  "sources": [{"id": "SOURCE-ID", "path": "ORIGINAL-LOCAL-PATH", "sha256": "ACTUAL-HASH", "captured_at": "ISO-8601", "role": "field_capture", "epoch_id": "FIELD-EPOCH-ID"}],
  "controls": [{"id": "POINT-ID", "reconstruction_xyz": [0,0,0], "site_xyz_m": [0,0,0], "role": "holdout", "measurement_method": "ACTUAL-METHOD", "uncertainty_m": 0.005, "evidence_source_ids": ["SURVEY-SOURCE-ID"], "observed_at": "ISO-8601", "object_id": "OBJECT-ID"}]
}
```

위 JSON은 필드 설명용이며 **실측 입력으로 사용할 수 없다**. 0 좌표·5mm 불확실성도 예시일 뿐 측정값이 아니다. `field_survey`에는 실제 측량 기록 파일을 연결한다. `reference_only`에는 공개 과거 자료를 연결하며 `epoch_id`를 새 현장 시점으로 붙이지 않는다. 파생 프레임에는 `derived_from`으로 원본 출처를 연결한다.

## 현장 단계 완료 확인

- 모든 구역의 촬영 커버리지와 모든 실제 객체의 ID·원본·설치 기준점이 연결됐는가.
- 승강기 각 층의 호출부와 객실이 동일 호기로 연결됐는가. 에스컬레이터 각 줄의 양 끝과 버튼 위치·좌우·운행 방향을 직접 확인했는가.
- 원본 사진·영상·측량 기록의 해시와 실제 촬영 시각이 보존됐는가. 게시일은 별도 필드인가.
- 독립 검증점을 정합에 섞지 않았는가. 미확인·가림·서로 다른 시점과 변경된 점포를 분리했는가.
- 아직 자료가 없는 객체를 확정 배치나 JEV 원인 후보로 표시하지 않았는가.
