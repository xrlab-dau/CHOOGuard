## 2026-10-09 원본 자동문 추가 반영

원본 버튼5개의 실제 유리 문짝/레일 소유자를 추적해 **자동문5개·원본 문짝9개(93면)**를 생산 씬에 저장했다. 가까운 임의 키트문 대신 각 버튼의 원본 계층과 고정 유리 뒤 주차 공간을 확인했다. 화면 배경과 정적 충돌 배경에서 같은93면을 각각 분리하고, 원본 재질/UV/법선/접선/색상과 고정 창틀·유리는 보존했다. 원본405컴포넌트와615디딤판을 유지하며,9문짝은 별도 원본 범주로 기록한다. [설치 receipt](../../.planning/2026-10-08-interior-runtime-completion/native-automatic-door-installation.json).

기존 누름판을2mm 눌러 정확한 문에 열림을 요청하는 구동을 연결했다. 실제 Unity 메시에서 앞면은+x이고 부착면은x=0이므로 누름 방향은−x다. 원본 보관 파일의 다른 좌표축을 그대로 쓰지 않았다. 버튼 해제/부품 제거 때 원본 정점·법선·접선과 메시 참조를 복원하고, 잘못된 축/깊이와 원본 두께를 넘는 동작을 거부하도록 고쳤다. 이름 없는 다섯 번째 출입구는 보수적인 `Staff` 시뮬레이션 정책을 적용했으며 실제 출입권한 분류는 미확인이다.

원본 여닫이3개는 이미 약110° 열린 자세이고 기존 키트 게이트와 닫힘 경로가 겹쳐 이번에 억지로90° 회전을 추가하지 않았다. 작동 미완료로 남아 있다.9문짝과5버튼의 닫힌 자세 이동은 각각 최대0.000134/0.000066모델m였으며 이는 원본 위치 보존 지표다. 최신 현실과의 정확도 인증이 아니다. 작동·회귀 검사는 별도 실행 기록을 따른다.

[workers/twin](../../workers/twin/README.md)은 출처 intake, 기존 참조 감사, 실측 정합, 독립 검증, Unity 좌표 변환, 객체 배치 export와 로컬 복원 실행을 제공한다. 정합에 사용한 점과 검증점을 분리하며, 잔차와 양의 측정 불확실성 합이 0.02m 이하여야 한다. 이미지·모델에서 읽은 치수를 현장 측량으로 인정하지 않는다. 예제는 미검증 촬영 키트이고 합성 시험값을 부산역 측량으로 배포하지 않는다.

Unity의 `MeasuredTwinImport`는 보존된 명세와 원자료 파일을 해시 검사하고 Python worker의 export를 다시 실행해 내용과 위치를 대조한다. 모델의 실제 가져오기 축척과 초기화 후 위치·크기도 검사한다. 배치 경로를 통과한 객체만 런타임 사건 입력에 들어갈 수 있고, 씬에 복사한 증빙만으로 신규 설비 자격을 얻지 못한다. 빌드와 씬 감사에서도 같은 근거를 확인한다. 이 검증은 측정된 기준점과 치수를 다루며 전체 표면·내부 구조·각도 정확도를 자동 인증하지 않는다.

```sh
.tools/video-reconstruction/bin/python -m unittest discover -s workers/twin -v
.tools/video-reconstruction/bin/python workers/twin/metric_pipeline.py audit-refs
```

실제 측정 명세가 있을 때 `validate`→`export-placement`→`MeasuredTwinImport.ImportVerifiedObject`로 연결한다. 공개 참조와 지금 생성한 상대 복원은 이 실장 단계의 합격 자료로 사용할 수 없다.

## 미완료 범위

사용자가 요구한 내부 건축 전체가 우선 범위다. 벽·천장·바닥·점포 내부/깊이·기둥·층간 연결·실제 개구부를 검증해야 하며, 사물 배치나 이동 가능한 경로만으로 완료 처리하지 않는다. 현재1F의 추정 점포 뒤쪽 경계와 화장실/계단 코어 입구,2F의 꽃들·복순도가 점포 깊이와 내부 벽,층간 개구부·점포 안쪽의 비관측 구간은 아직 확정되지 않았다. 확인된 공개 사진과 기존 원본 구조를 대조하면서 잘못된 폐쇄 벽·누락 벽을 구간별로 수정해야 한다.

6개새복원 블록의 전역 위치를 강제로 맞추지 않았다. 동일 글자를 직접 다중 시점 삼각측량한 대응점으로 검증했지만, 현재 모델의 사진 quad와 상대 복원 사이에 별도 재투영 오차24.6/60.3px와 소유자별 축척 불일치가 남는다. 사진 원근·모델 quad·복원 오차를 실제 건축 치수 하나로 단정할 수 없다.

기존 [scene-coverage.json](scene-coverage.json)은 첫 구현 단계의 역사적 집계다. 현재 감사는 [.planning 건축 자료](../../.planning/2026-10-08-interior-runtime-completion/architecture/)에 보존하며, 메시/컴포넌트 수를 현장 시설 전수 완전성으로 세지 않는다. 현장2cm오차 목표·독립 실측은 미검증이고 새 실측 배치 설비는0개다. 이것이 건축 복원 작업을 생략하는 이유가 돼서는 안 된다.

운영 기능에는 나머지 승강장15lane의 손잡이 고무·숨은 리턴 구조, 다른 승강기 객실·shaft 연결, 경로가 충돌하는 원본 여닫이3개, 미분리/미연결 조작부, 장비 운반·다단계 조작·통제선 설치·부상자 지원·직무 권한의 확장이 남아 있다. 15lane의 원본615디딤판 구동과 기존5버튼/9자동문짝 연결은 이번 파동에서 실제 반영·시험했다. DoorCloser고장 초안은 컴파일 심볼로 비활성 상태이므로 구현된 실제 사건으로 세지 않는다.

## 검증 기록

검증은 [.planning/2026-10-08-measured-twin-execution](../../.planning/2026-10-08-measured-twin-execution/)에 보존한다. Python 명세 검사 **24개**, Unity 대상 검사 **31개**(배치 11, 인계 3, 설비 7, 기계 연결 8, 실제 씬 실내/업무 1, 길 안내 1)의 최종 실행이 통과했다. 앞선 길 안내 기본값 검사 12개도 통과했다. Blender 추출·재개방은 **PASS**다. 실제 현재 배치 파일과 씬의 빌드 근거 검사를 실행했고 컴파일 오류 0, 편집기 재생/컴파일/미저장 씬 상태 false를 확인했다. 전체 플레이어 빌드를 생성한 것은 아니다.

길 안내 검사는 한 실행에서 기존 1mm 비교 기준에 대해 경로점 63이 약 1.4mm 변동해 실패했고, **시험이나 허용오차를 바꾸지 않은 재실행은 통과**했다. [간헐 변동 기록](../../.planning/2026-10-08-measured-twin-execution/navigation-intermittent.json)을 남겼다. 최종 통과와 이 변동을 함께 해석해야 한다.

실제 씬 업무 검사에서는 소방 팀을 생성해 다른 인지한 연관 화재로 재배치하고, 즉시 위치 이동 없음·미도착 상태·새 이동 경로·화재 접근 거리·작업 중 재배치 거부를 확인했다. 모든 직무와 장시간 출동의 현장 품질 검증을 대신하는 검사는 아니다.

이 작업의 추가 실제 씬 시험과 렌더에서도 Unity의 `Graphics Ring Buffer space`와 기존 글꼴 경고가 반복됐다. 컴파일·검사 실패는 없었지만, 전체 객체를 확장한 씬의 장시간 성능·메모리 품질은 별도 검증이 남아 있다. 글로벌 편집기 실행 옵션은 변경하지 않았다.

JEV 호출을 꺼 둔 실제 씬 회귀 검사이며, 원격 생성 품질이나 현장 실측 검증 결과로 해석하지 않는다. 새 유료 작업·외부 배포·Unity Cloud 작업은 수행하지 않았다.

2026-10-08~09 추가 검증: 원본 분리EditMode2, 실제 문짝작동Play1, 연속승강기Play9, 지상발판분리EditMode8, 실제탑승/seamPlay3, 시민동행Play1, 중복건축소유자EditMode4, ARTBOX부분절단·UV보존·잘못된입력EditMode9가 통과했다. 모두 해당 구현 범위의 검사이며 전체 내부 공간 정확도 인증이 아니다. 실제 저장된 씬과 렌더를 확인했고, 전체 플레이어 빌드를 생성하지 않았다.

[전후 경로 검사](../../.planning/2026-10-08-interior-runtime-completion/native-door-navigation/after-baked-path-audit.json).

## 3F 부산옥의 잘못된 폐쇄 벽 수정

[2026-08-09 게시된 실제 방문 사진](https://m.blog.naver.com/pshbadgirl/224373114211)의 두 수직 유리 면과 기존 RY2 영상의 연속된 점포·맞은편 동선을 대조했다. 시래마을/현재 비빔가 방향의 `v36.5` 측면을 막던 벽4면만 제거하고, 나머지 벽8면과 정면 유리·문·천장을 보존했다. 기존 정면의 유리 높이·창틀 단면·걸레받이·상부 띠와 재질을 재사용한4개 시각 메시344면을 실제 씬에 저장했다. 고정 유리 경계는 기존4면을 별도 MeshCollider에 정확히 옮겨 통과할 수 없는 실제 경계를 유지한다. [동일 진단 카메라 전후 비교](visuals/busanok-glazed-return-source-before-after.png), [사진·영상·면별 근거](../../workers/twin/evidence/current-upper-floor-20261009/README.md).
