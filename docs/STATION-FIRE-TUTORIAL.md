# 역무원 화재대응 튜토리얼 — Issue #318

처음 배우는 사람이 목적과 입력을 이해할 수 있는 고정 시나리오이며, 행동의 결과는 실제 물체·인물·현장 상태로 나타난다. 그래픽 개편과 역사 형상 변경은 포함하지 않는다. 외부 AI 응답은 정상 진행의 조건이 아니다.

## 현장과 역할

플레이어는 역무원이다. 기존 저장 맵의 1층 매장 좌석에서 일반 가연물 화재가 발생한 교육 상황이다. 기존 `C165_S01_OBSERVED_CHAIR_1_0_1` 의자와 약4.61m 떨어진 `C165_S01_P5_SOURCE_LEFT_ENTRY_PORTABLE_EXTINGUISHER`를 사용한다. 소화기의 원래 위치·외형은 유지하며 실제29개 분리 메시를 조작 대상으로 연결한다. 고정 받침은 운반에서 분리한다. 새 장비·연소통·상자·거치대를 현장에 생성하지 않는다.

이 위치는 현재 게임 맵에서 확인한 배치이며 현행 실역 실측, 실제 화재 재현, 승인된 피난계획을 뜻하지 않는다. 소화기 부품 인출 거리·레버 각도·분사 거리·속도·잔량·초 단위 값은 모델 기반 게임 튜닝이다.

## 학습 흐름

1. 불과 연기를 발견하고 가까운 승객에게 위험과 열린 통로 방향을 안내한다.
2. 기존 Q 무전 휠에서 위치를 보고하고 신고·지원 역할을 요청한다.
3. 승객과 동료가 이동하는 동안 원래 비치된 소화기를 찾아 가져온다.
4. 핀·노즐을 준비하고 자신의 퇴로를 확인한 뒤 가능한 초기소화를 수행한다.
5. 분사를 멈추고 관찰한 결과와 미확인 사항을 무전으로 전달한다.
6. 명시적인 시간 경과 뒤 도착한 소방대에게 상황을 전달한다. 동료A는 기존 옆 대기점까지 화점을 피하는 실제 경로로 이동해 접근 통로를 비우고, 동료B는 승객 안내를 이어간다. 다른 동료와의 대화는 소방대 상황 전달로 기록하지 않는다. 소방대가 현장 확인을 시작하며 역무원의 초기 대응 학습을 마친다.

승객 전원의 목적지 도착, 동료 도착, 음성 재생 종료, 벨트 설치를 장비 준비의 선행 조건으로 삼지 않는다. 플레이어의 긴 호송과 차단대 운반·설치는 없다. 사람은 안내 후 실제로 이동하며 버튼으로 대피 완료 처리되지 않는다.

## 입력과 반응

|행동|입력|확인할 반응|
|---|---|---|
|위험·방향 안내|가까운 승객을 보고 E|주변 승객이 열린 통로로 이동|
|보고·지원 요청|Q 유지, 방향 선택, 좌클릭 묶음 열기, Q 놓아 전송|접수 응답과 동료의 실제 지원 행동|
|장비 확보|기존 소화기로 걸어가 F, G로 내려놓기|원래 거치 위치가 비고 같은 물체를 운반·재집기|
|핀·노즐 준비|부품 조준 후 좌클릭 유지와 화면 인출 방향 드래그 또는 휠 위로|실제 부품 이동, 잡힘과 준비율 표시, 중간 해제·재잡기 상태 유지|
|분사|레버 좌클릭 유지, 놓아 중지|노즐 방향·분말·소리·잔량·화재 반응 연결|
|결과 전달|Q 보고 묶음|초기소화 결과와 잔류 위험의 불확실성 전달|
|소방대 상황 전달|안전한 통로에서 가까이 가 E|관찰한 상황을 전달하고 소방대가 확인을 이어감|

승객 보행은 플레이어 몸과 운반 중인 실제 소화기 메시 범위를 각각 피한다. 이 회피 범위는 보행면을 깎지 않으며, 실제 장비·인물 충돌은 유지한다. 핀·노즐 준비 때는 장비를 안정적으로 두고, 준비한 레버를 잡은 동안에는 몸의 수평 조준 방향으로 장비를 함께 돌린다. 이때도 실제 회전 충돌을 통과하지 못한다. Q 메뉴는 장비 입력을 소비하며 핀 준비·운반 상태를 보존한다. 메뉴·일시정지는 분사와 잡기를 해제하고 자동 재분사나 잔량 복구를 하지 않는다. 물리 콜라이더를 확대하는 대신 보이는 부품 주변의 조준 허용 범위와 가림 확인을 사용한다.

## 핀 결함의 근거와 검증 범위

사용자는 드래그와 반복 휠을 모두 시도했지만 진행되지 않았다고 보고했다. 설치된 Input System1.20의 기본 정규화 휠 값±1을 기존 코드가 다시120으로 나누는 결함을 확인했다. 과거 검사는 매 프레임120을 직접 넣어 이 문제를 가렸다. 가로축만 사용하던 드래그도 실제 인출 방향과 일치하지 않았다.

수정은 일반 장치 입력에서 휠 칸 단위를 정규화하고, 실제 부품 이동 방향을 화면에 투영해2차원 드래그를 처리한다. 일반 Update 경로에 MouseState 이벤트를 넣는 검사와 실제 원래 장비를 사용하는 전체 씬 검사를 구분한다. 자동 입력 완주를 초행 사용자 사용감 승인으로 확대하지 않는다. 최신 검사 결과는 로컬 검수 보고서로 확인한다.

## 안전·종료 경계

정상 학습은 주변 안내와 보고, 열린 퇴로가 있는 작은 화재의 초기소화다. 약제 소진이나 중단 보고 때에는 분사를 멈추고 잔류 화재를 전달할 수 있다. 재충전·화재 강제 완료·위험 중 계속 진압을 요구하지 않는다. 선로 진입, 전기·가스·관제 설비 조작, 전체 영업 재개 결정은 포함하지 않는다.

소방대에 전달하는 것은 확인한 화재 위치·실시한 조치·주변 승객 안내와 미확인 사항이다. 일반 역무원의 상황 전달과 책임자의 공식 지휘권 인계를 구분한다. 역사 전체 전원 대피, 부상자 없음, 잔불 없음이나 완전 안전을 플레이어가 임의로 선언하지 않는다. 도착 시간은 실제 출동 시간의 측정·재현이 아니라 표시된 교육용 시간 압축이다.

현재 `TrainDepartureDemo`의 **훈련 선택 → 화재 튜토리얼**에서 시작하며 종료하면 훈련 선택으로 돌아온다. 기차 튜토리얼과 **비상상황 연습 → 환자 발생 → 심정지 · AED**, **비상상황 연습 → 화재 → 맞이방 작은 불**은 별도 항목으로 보존한다. 심정지의 기존 시작·환자 생성·복귀 검사와 전체 CPR 수동 검수는 구분한다.
