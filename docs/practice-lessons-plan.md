# 계열별 세부 연습 (순서 점수)

비상상황 연습 메뉴(`docs/practice-menu.md`)의 모든 상황에 순서 점수를 붙였다(2026-11-22). PR #339가 develop에 머지된 뒤(2026-11-24) 로컬 `feat/practice-order-lessons`(develop `a623e21816`에서 분기)로 옮겼고 아직 커밋하지 않았다.

- **세부 순서표가 있는 상황**: `docs/emergency-lesson-steps.md`의 표 번호를 그대로 쓰는 전용 연습을 따로 만들었다.
- **순서표가 없는 상황**(열차 하부 연기, 출입문 끼임, 선로 추락·진입): 공통 순서(`CommonOrderLesson`)로 채점한다. 순서표가 생기면 따로 만든다.
- 심정지(`CardiacTutorialLesson`)와 맞이방 작은 불(`FireTutorialLesson`)은 그대로 둔다.

연습 하나는 세 가지를 적는다.

- **단계**: 표의 번호와 이름, 그 단계를 알리는 신호. 표에서 **(신규)**인 단계는 신호가 없어서 뺐다.
- **규칙**: 세 모양이 있다.
  - **선행**: "A 전에 B를 하면 감점"
  - **금지**: "C를 하면 감점"
  - **필수**: "B 없이 인계하면 감점"
- **근거**: 클래스 주석에 근거 번호를 적었다. S/P/E/Q 번호는 로컬 전 계열 근거 문서(`docs/emergency-procedures-evidence.local.md`)의 것이다. develop의 `docs/emergency-procedures-evidence.md`는 화재 F1~F9만 검토했다.

### 신호는 이미 모이는 자리에서 받는다

| 신호 | 보내는 곳 |
|---|---|
| E·R 상호작용 성공(실행 전 문구) | `FirstPersonResponder.InteractionPerformed` (새 이벤트) → `EmergencySession.OnInteractionPerformed` |
| 역무실 보고 | `IncidentDirector.Report`(견학), `IncidentDirector.ReportSlots`(표준·실전) |
| 기관 요청 | `IncidentDirector.RequestTeam` (`TeamRequests` 문구) |
| 설비 요청 | `IncidentDirector.RequestMeasure` (`MeasureRequests` 문구) |
| 방송 범위 | `IncidentDirector.Broadcast`, `IncidentDirector.Announce` (`ScopeName` 문구) |
| 현장 인계 | `IncidentDirector.ReviewAndHandOver` 성공 |

결과 화면(`ShiftResult.Show`)의 수치 칸에 점수, 감점 내역, 한 단계 목록(●한 단계 ○ 안 한 단계)이 붙는다.
