# 실제 확인 범위

- 기존 HTML 전달물과 PRD v11의 Unity 요구를 대조했다.
- 현재 manifest/lock을 읽어 native UI 패키지 도입 조건을 확인했다.
- 새 Markdown/JSON/C# 소스를 생성했다.
- 정적 패키지 검사는 파일·타겟·식별자·미실행 상태·기본 생성 API 문자열을 확인한다. C# 컴파일 시험이 아니다.
- Unity Editor/Player가 이 환경에 없으므로 컴파일·레이아웃·버튼·IME·렌더·기하·성능은 미실행이다.
- C# 소스의 실제 API 호환성과 레이아웃은 Unity 입고 후 검수해야 한다.
- 모든 사용자 과업을 구현한 제품도, 완성된 gameplay prototype도 아니다.
- S01–S12를 native GameObject 계층으로 여는 레이아웃 시작점이다.
- 카메라·월드 선택·미니맵·접근성 설정·운영 결과는 코드에 없는 기능이다.
- UGUI/TMP와 프로젝트 한글 폰트가 먼저 준비돼야 한다. 폰트 파일은 제공하지 않는다.
- 원격 저장소·PRD·#222·기존 HTML 파일을 수정하지 않았다.
