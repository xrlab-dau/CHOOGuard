# 새 구축 명세 검사

기준일: 2026-09-19. 검사 대상은 이 전달 패키지의 문서·JSON·문맥 조회기다. Unity 제품이나 실제 저장소 구현을 검사한 것이 아니다.

## 실제 수행
- 새 에픽 11개, 구현 작업 45개, 제품 요구 91개, 향후 제품 인수시험 91개의 식별자·연결을 검사했다.
- 정상 명세와 의도적으로 손상시킨 입력을 포함한 Python 시험 14개를 실행했다.
- 최초 검사에서 합본 IMPLEMENTATION_SPEC.md의 상대 링크 오류가 발견되어 해당 테스트 1개가 실패했다. 22개 상대 링크의 기준 경로를 수정했다. 최초 결과는 initial-plan-check.json 및 initial-unittest.txt에 보존했다.
- 수정 후 전체를 다시 실행하여 14개 모두 통과했다. 최종 plan-check.json의 errors는 빈 배열이다.
- 모든 45개 작업의 문맥을 실제 추출했다. 최대 출력은 11,096 UTF-8 바이트다. 예산 초과 시 필수 조건을 자르지 않고 complete=false와 재조회 명령을 반환하는 반례도 검사했다.
- 새 데이터·활성 문서에 과거 에픽 번호·Foundation 코드·과거 커밋·기존 work-order·원격 코드 링크를 실행 의존성으로 남기지 않았다. 검사기의 반례 입력은 의도적으로 금지 문자열을 포함한다.
- 새 작업 파일 쓰기 소유권의 중복과 조건부 의존성을 포함한 순환을 검사했다.

## 해석 제한
제품 요구를 새 작업에 연결했다는 것이 실제 사용자 효과나 물리 정확도를 검증했다는 뜻은 아니다. 각 작업의 정상/반례 90개와 제품 인수시험 91개는 앞으로 실행할 명세이며 현재 NOT_RUN이다. 테스트 수를 합산해 제품 품질 점수로 사용하지 않는다.

원격 저장소 열람·초기화·삭제·force push·이슈/담당자/보드 수정은 수행하지 않았다. 이 패키지는 계획/명세/문서 도구만 포함하며 Unity 프로젝트·C# 제품 구현·컴파일·실행을 완료한 전달물이 아니다. 무료 에셋/매뉴얼/기술 원문은 이전에 조사한 후보 링크만 활용했고 이번에는 새 취득이나 현행성 재검증을 수행하지 않았다.
