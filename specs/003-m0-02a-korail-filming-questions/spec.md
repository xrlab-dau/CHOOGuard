# Feature Specification: M0-02a KORAIL 촬영 승인 질문 준비

**Feature Branch**: `feature/m0-02a-filming-questions`

**Created**: 2026-09-06

**Status**: Draft (1차 검토 반영, 독립 재검토 미완료)

**Input**: 백로그 v1.3 §4 M0-02a, 기준선 MAP-01~03, O-02~O-05, 발견 v1 Q4

**Data Class**: PUBLIC_SYNTHETIC. 질문 초안에는 실제 역사·구역·일정·담당자 정보를 넣지 않는다. 실제 회신은 M0-02b에서 저장소 밖 TEAM_INTERNAL 이상으로 관리한다.

**ID 규칙**: FR-00n과 SC-00n은 이 변경 단위 로컬 ID다.

## User Scenarios & Testing

### User Story 1 - 승인 조건을 빠짐없이 묻는 초안 (Priority: P1)

XR 책임자는 구역·기기·시간·용도·저장·처리·공개 조건을 각각 질문한다.

**Independent Test**: 조건별 질문 수, 답변 형식, 가장 제한적인 무응답 기본값, 의미 있는 상위 ID 참조를 대조한다.

**Acceptance Scenarios**:

1. **Given** 질문 초안, **When** 조건 태그를 집계하면, **Then** 일곱 조건 각각에 질문이 하나 이상 있다.
2. **Given** 질문 하나, **When** 추적을 확인하면, **Then** 적용 가능한 MAP-01~03 또는 O-02~O-05를 하나 이상 참조한다. 비적용 ID는 N/A와 이유를 적으며 의미 없는 양쪽 ID 강제 부착을 하지 않는다.
3. **Given** 용도 또는 처리·공개 조건에 답이 없으면, **When** 기본값을 적용할 때, **Then** 촬영·처리·외부 전송·공개를 허용하지 않는다.

### User Story 2 - PM 검토와 정제 실행 증거 (Priority: P2)

PM은 일곱 조건과 촬영 금지 대상·외부 전달 범위·공개 범위를 검토한다. 원본뿐 아니라 중간 결과와 정제 산출물의 보관·전송도 확인한다.

**Independent Test**: PM 검토표와 정제된 실행 기록의 대상 해시가 일치하고 모든 검토 항목을 통과해야 한다.

### User Story 3 - 미작성 승인 양식 (Priority: P3)

승인자 이름·직위·소속·날짜·연락 경로, 일곱 조건, 서면 회신의 근거 위치를 담는 빈 양식만 만든다. 실제 승인자·회신은 입력하지 않는다.

**Independent Test**: 필드 존재를 확인하고 양식에 실제 승인이나 회신이 들어 있지 않은지 사람이 검토한다.

## Requirements

- **FR-001**: `docs/korail/filming-approval-questions-v1.md`는 촬영 구역, 기기, 시간, 촬영·처리·교육·검증·대회 시연 용도, 촬영 금지 대상, 저장, 처리, 공개 절을 가진다. 저장·처리 절은 원본 촬영물, DA3/Open3D 중간 결과, 정제 맵·스크린샷·영상 각각의 위치·보관 기간·저장소 반입·반출 범위를 묻는다. 용도 미응답과 승인 외 재사용은 촬영·처리·전송·공개 금지다.
- **FR-002**: 질문마다 조건 태그, 적용 가능한 상위 MAP/O ID, 비적용 이유, 선택형 또는 서술형 답변 형식, 무응답 기본값을 기록한다. 처리 위치·외부 모델·MCP·API·인터넷 경계를 묻는 질문은 O-05를 추적할 수 있다.
- **FR-003**: 미응답은 승인으로 바꾸지 않는다. 원본·중간 결과·정제 결과 각각 저장소 반입·외부 전송·공개 금지를 기본값으로 한다. 일부 회신은 조건별 미결 상태로 남기며 전체 촬영 착수 승인으로 간주하지 않는다. 구두 답변만으로 서면 승인 게이트를 통과하지 못한다.
- **FR-004**: 실제 역사명·구역·일정·담당자명은 초안에 넣지 않는다. 합성 표기와 빈 필드만 허용한다. 실제 정보가 입력되면 호출을 중단하고 이미 전송됐다면 사고로 보고한다. 세션 삭제만으로 미전송을 주장하지 않으며 원문을 재기록·재전송하지 않는다.
- **FR-005**: `docs/korail/filming-approval-record-template-v1.md`에 승인자 식별 다섯 필드와 일곱 조건을 둔다. 작성된 양식은 PM이 지정한 저장소 밖 보관 위치로 관리한다. 공개 저장소에는 실제 경로·연락처를 넣지 않는다.
- **FR-006**: `docs/evidence/M0-02a/pm-review.md`에 일곱 조건, 촬영 금지 대상, 외부 전달 범위, 공개 범위의 검토 결과·날짜·승인 역할·대상 해시를 기록한다. 에이전트를 사용한 경우 입력·출력 자료등급, 실제 제공자·모델, 프롬프트·출력 해시, 전송 목적지 또는 호출 0건, 정제 규칙 버전·결과, 정제된 사고 기록을 추가한다. 관측하지 않은 필드는 unknown으로 남기고 검증 통과를 주장하지 않는다.
- **FR-007**: 에이전트는 PUBLIC_SYNTHETIC 전용 실행 사본에서만 작업한다. 자격 파일·키·KORAIL 경로는 mount하지 않으며 읽기·쓰기를 모두 거부한다. 네트워크는 기본 거부하고 별도 승인된 모델·개발 목적지만 허용한다. M1-02~04 실행 경계 시험 전 실제 자료 연결은 금지한다. 프롬프트 지시만으로 경계가 강제됐다고 판정하지 않는다.
- **FR-008**: PM 검토 또는 독립 검토 뒤 질문·양식·정책·대상 해시가 바뀌면 영향 검증과 독립 재검토를 수행한다. 확정 증거는 덮어쓰지 않는다.

## Success Criteria

- **SC-001**: 일곱 조건 각각 질문이 하나 이상이며 원본·중간 결과·정제 결과의 저장·전송 경계가 모두 있다.
- **SC-002**: 모든 질문에 의미 있는 상위 참조, 비적용 사유, 답변 형식과 기본값이 있다.
- **SC-003**: PM 검토 열 항목이 모두 통과하며 검토 대상 해시와 FR-006 기록이 일치한다.
- **SC-004**: 합성 자료만 사용했음을 사람이 확인하고 실제 정보·자격·민감 경로 검출이 없다. 단순 금칙어 검사만으로 이 기준을 통과시키지 않는다.
- **SC-005**: 무응답·부분 회신·구두 회신·허용되지 않은 전송·검토 뒤 변경의 각 시험이 착수·공개 승인을 생성하지 않는다.

## Applicable Definition of Done

백로그 §2 중 1, 2, 3, 4, 6, 7, 8, 11, 12가 적용된다. 실제 회신 수신과 촬영 승인은 M0-02b의 범위이며 미완료 상태를 유지한다.
