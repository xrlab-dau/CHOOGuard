# Requirements Quality Checklist: M0-02a 촬영 승인 질문

- 날짜: 2026-09-06.
- 대상: [명세](../spec.md).
- 상태: 1차 changes_required 반영 후 자체 서술 점검. 독립 재검토 미완료. 실제 질문·회신·촬영 승인 통과 기록이 아니다.

## 명확성·완전성

- [x] CHK001 구역·기기·시간·용도·저장·처리·공개를 요구했다. FR-001.
- [x] CHK002 원본·DA3/Open3D 중간 결과·정제 맵·이미지·영상의 위치·보관·반출을 구분했다.
- [x] CHK003 각 질문에 의미 있는 MAP 또는 O 참조와 비적용 이유·답변 형식·무응답 기본값을 요구했다. O-05를 포함한다. FR-002.
- [x] CHK004 부분·구두·무응답과 승인 외 재사용이 착수·전송·공개 승인을 만들지 않는다. FR-003.
- [x] CHK005 실제 정보 입력 시 중단·정제 사고 보고하며 세션 삭제를 미전송 증거로 쓰지 않는다. FR-004.
- [x] CHK006 승인자 식별 필드는 빈 양식에만 두며 실제 회신은 저장소 밖에서 관리한다. FR-005.

## 일관성·검증

- [x] CHK007 PM 검토의 대상 hash와 전송·제공자·정제·미관측 unknown 기록을 요구한다. FR-006.
- [x] CHK008 모델 밖 읽기·쓰기·네트워크 경계와 합성 입력, M1 시험 전 실제 자료 금지를 요구한다. FR-007.
- [x] CHK009 DoD 12와 변경 후 영향 검증·재검토·append-only를 적용한다. FR-008.
- [ ] CHK010 질문·미작성 양식과 PM 검토표가 구현되고 사람이 실제 정보 미포함을 확인했다.
- [ ] CHK011 무응답·부분·구두 회신·미승인 전송·변경 뒤 재검토 부정 시험이 실행됐다.
- [ ] CHK012 최신 불변 manifest에 대한 모든 필수 독립 관점이 승인했다.
