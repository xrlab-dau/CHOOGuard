# CHOOGuard VR — 철도역 비상 상황 대응 훈련

가상현실수업 Term Project 제안서 · 2026.10.05  
CHOOGuard Studio · [제안서 10장](https://www.figma.com/design/yjr4pc5IyZSaporxTPivg1/?node-id=154-2)

## 1. 제작 취지

철도역의 비상 상황을 공간 속에서 관찰하고 직접 행동하는 XR 훈련을 제작한다. 사용자는 시야·소리·표지를 통해 주변 상황을 파악하고, 장비와 안내 요소를 조작하며 필요한 대응 행동을 선택한다. 수행 후에는 행동 순서와 소요 시간을 확인하고 같은 상황을 다시 연습한다.

대표 시나리오는 대합실의 연기 이상 상황을 발견하고 안내하는 훈련이다. 조작 안내 → 상황 관찰 → 신고·안내 → 목적지 이동 → 결과 확인으로 구성하며, 목표 체험 시간은 5–7분이다.

## 2. 개발 요구사항 및 개발 환경

| 요구사항 | 구현 내용 |
|---|---|
| 훈련 공간 | 역사 구역 1개 |
| 비상 상황 | 로컬 시나리오 1개 |
| 핵심 조작 | 무전기 집기·놓기, 안내 버튼 선택, 목적지 이동 |
| 결과 화면 | 행동 순서, 완료 시간, 누락 항목 |
| 실행 기능 | 시나리오 시작·종료·재시작 |

개발 환경은 Unity 6.3 LTS, C#, URP, Input System, XR Interaction Toolkit, XR Origin, XR Interaction Simulator, Blender, Git, macOS로 구성한다. 키보드·마우스로 가상 머리와 컨트롤러 입력을 시뮬레이션한다.

## 3. 기술적 특징

XR 입력을 공간 상호작용 → 상황 상태 → 결과 기록으로 연결한다.

- **Direct / Grab:** 가상 손으로 무전기를 집고 놓으며 장비의 선택 상태를 제어한다.
- **Ray / Select:** 포인터로 안내 버튼을 선택하고 시각·소리 피드백을 제공한다.
- **Teleport:** 도착 지점을 지정하며 훈련 공간 안에서 이동한다.
- **상황 상태:** 시나리오 진행과 장비·NPC의 상태 변화를 연결한다.
- **결과 기록:** 행동 이벤트와 시간을 기록하고 결과 요약·재시작 기능을 제공한다.

## 4. 주단위 구현계획

| 주차 | 구현 내용 | 산출물 |
|---|---|---|
| W1 | 입력 액션·시뮬레이터, 가상 컨트롤러 연결 | 입력 테스트 씬 |
| W2 | 역사 구역 구성, 시점·Teleport 이동 | 공간 이동 씬 |
| W3 | 무전기 집기·놓기, Ray 안내 버튼 연결 | 장비 조작 모듈 |
| W4 | 상황 발생·진행 상태, 목적지 선택·안내 동선 | 통합 시나리오 |
| W5 | 행동 순서·시간 기록, 누락 항목·결과 요약 | 결과 요약 화면 |
| W6 | 시작→대응→결과 연결, 재시작·반복 실행 | 통합 플레이 데모 |
| W7 | 실행 빌드 제작, 프레임 측정·성능 개선 | 데스크톱 실행 빌드 |
| W8 | 시연 영상·보고서, 프로젝트·발표자료 정리 | 최종 프로젝트 |

## 5. 결과물 형상

현재 개발 화면은 부산역 외부 광장·역사 대합실·승강장·열차 출입구·객실 내부 이동 장면으로 구성한다. 제공된 「맵소개 영상」과 「플레이 영상」에서 캡처한 실제 장면을 제안서와 중간보고에 수록한다.

완성 목표는 가상 손과 Ray 포인터, 안내 버튼, 훈련 진행 정보를 연결하는 XR 화면이다. 결과 화면에는 행동 순서·완료 시간·누락 항목·다시 시작을 표시한다. 제안서 7장에 현재 개발 화면과 완성 목표 화면을 함께 제시한다.

최종 결과물은 Unity 프로젝트, 실행 빌드, 시연 영상, 구현 보고서로 구성한다.

## 6. 기대효과

공간을 관찰하고 상황에 맞는 행동을 선택하는 반복 훈련 환경을 제공한다. 입력·집기·공간 UI·기록을 연결하며 XR 인터랙션을 구현하는 경험을 얻는다. 같은 상황을 다시 수행하고 행동 기록을 비교하며 대응 흐름을 돌아볼 수 있다.
