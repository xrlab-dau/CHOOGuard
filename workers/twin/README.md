# Metric twin pipeline

This worker implements source intake, legacy evidence audits, physical-control registration, independent holdout validation, Unity placement export, and a real pycolmap/OpenMVS reconstruction command chain. It does not contain a new field survey or certify existing Busan geometry. The capture kit is explicitly unverified. Public old images/videos and model screenshots remain `reference_only`.

Use the existing environment; no new service or paid job is needed:

```sh
.tools/video-reconstruction/bin/python -m unittest discover -s workers/twin -v
.tools/video-reconstruction/bin/python workers/twin/metric_pipeline.py audit-refs
.tools/video-reconstruction/bin/python workers/twin/metric_pipeline.py record-source asset-library/path/to/photo.jpg --id reference-photo --role reference_only
```

`record-source` reads the real file and prints its SHA256 record. It does not alter the source or guess capture dates. Explicit field roles require supplied capture time and epoch; the `field_survey` role is a provenance declaration requiring human review, not proof generated by this tool. A reconstruction, diagram, image measurement or model fit must never be assigned `field_survey`.

## Input and acquisition

Copy `examples/capture-kit.unverified.json` to a new project-local acquisition directory. Replace placeholders with actual records before clearing `template_unverified`. Keep source media and survey files in the project. Capture epoch is one acquisition window with timezone-aware start/end; source and measurement times must lie inside it. Reference-only sources can have older/unknown dates but cannot support physical placement checks.

Acquire overlapping photos or stable videos with loops and cross-pass coverage. Record entrances, floor links, occluded areas, object fronts/sides, control details and label closeups. Capture moving objects at the selected reference time. For repeated patterns, provide cross-angle views. Review people, motion blur, glass and mirrors before meshing. The worker will not fill invisible rooms or accept disconnected models as one metric space.

Establish a physically documented right-handed metre datum with fixed, distributed control points and measured heights. Use at least three non-collinear fit points and three distinct non-collinear holdouts; retain independent field-survey logs and strictly positive bounded measurement uncertainty. Prefer spread across floor heights and region corners. Keep holdout IDs and physical landmarks separate from fit controls. Do not tune the model against heldout coordinates and then reuse them as independent validation.

The explicit `coordinate_frame.unity_from_site` orthogonal matrix must have determinant -1 and a metre translation. It maps the right-handed survey frame to Unity left-handed x-right/y-up/z-forward. Merely renaming axes is rejected. The template axis swap and zero translation are examples; the actual scene datum must be registered independently.

Every verified object requires an exact object anchor tagged `object_id` on one holdout, three independently measured dimensions with distinct Unity `axis` values x/y/z, a retained current capture source, and explicit survey-backed `rotation_unity_euler_deg`. Dimension values refer to the object's local bounds axes in the declared Unity orientation. Orientation baseline uncertainty is recorded but does not itself establish an angular-accuracy certificate; inspect the measured orientation against actual object geometry. A group fit alone cannot verify an unmeasured object's pose or dimensions.

## Commands and outputs

```sh
.tools/video-reconstruction/bin/python workers/twin/metric_pipeline.py audit --manifest content/world/acquisition/capture.json
.tools/video-reconstruction/bin/python workers/twin/metric_pipeline.py validate --manifest content/world/acquisition/capture.json --output workers/twin/output/validation.json
.tools/video-reconstruction/bin/python workers/twin/metric_pipeline.py export-placement --manifest content/world/acquisition/capture.json --object-id EXACT_OBJECT_ID --output workers/twin/output/placement.json
.tools/video-reconstruction/bin/python workers/twin/metric_pipeline.py reconstruct --manifest content/world/acquisition/capture.json --output workers/twin/output/region-unique
```

`reconstruct` defaults to a non-mutating command preview after input audits. `--execute` runs the listed commands in a fresh output directory, copies photos/extracts video frames, runs CPU pycolmap feature extraction/exhaustive matching/mapping/undistortion, and executes local OpenMVS interface/densify/mesh/refine/texture binaries. It preserves stage logs and exit receipts. It refuses fewer than three images, more than 1200 images in one region, disconnected reconstruction, or fewer than 90% registered cameras. A reconstruction is always labelled `metric_verified:false` until independently registered; low reprojection error is not centimetre accuracy. Split large captures into overlapping regions. Existing outputs are preserved.

`validate` uses a proper similarity transform fitted only to fit controls. For each untouched holdout it recomputes predicted site XYZ and residual; conservative acceptance requires residual plus supplied bounded measurement uncertainty <=0.02m. It outputs `validated`, `failed`, or a blocked error with reason. Source hashes, date/epoch consistency, field provenance, missing files, duplicate IDs/points, degenerate scale, model-derived controls and coordinate conversion are checked. Holdout coverage verifies measured points only; arbitrary unobserved geometry still requires new observations and checks. Fitted-transform uncertainty is not a global certificate; holdout errors and measurement bounds must be interpreted with the actual survey's quality/coverage.

`export-placement` reruns validation from original manifest bytes. It exports `schema:chooguard.verified-placement.v1`, the site coordinate mapping, Unity-world position/explicit rotation, and the exact C# `verification` record: object/epoch/frame IDs, manifest hash/path, physical source hash/path/date/role, disjoint fit IDs, exact object holdout positions, and 3-axis dimensions. All exported paths are project-relative. The Unity importer must rehash the retained files and verify the instantiated object's pose and dimensions. Numeric summary errors are supplementary; the C# gate recomputes errors. Orientation and visible surface quality need separate review.

Output files are created only when absent. Validation does not mutate source manifests, actual models or scene state. Synthetic unit-test fixtures are created in temporary directories and cannot be used as Busan survey evidence. No example placement with fabricated coordinates is shipped.

## Public reference reconstruction pilot

Historical public footage can be reconstructed separately for visual comparison and relative geometry study using `reference_study.py`. It explicitly requires `--reference-study`, never produces field validation or placement export, and keeps `role:reference_only`, `metric_verified:false`, `placement_export_allowed:false`. Upload date remains separate from an unknown capture date. The output is a study of a selected clip, not a current as-built interior.

```sh
.tools/video-reconstruction/bin/python workers/twin/reference_study.py --reference-study --source asset-library/research-public/2026-10-08/measured-twin/clips/RY2qvE0Tugk_041-154.webm --source-url 'https://www.youtube.com/watch?v=RY2qvE0Tugk' --source-id RY2qvE0Tugk --upload-date 2023-05-01 --clip-start 15 --duration 12 --fps 2 --width 720 --output workers/twin/output/new-reference-study --texture --execute
```

Omit `--execute` for a non-mutating preview. A small M1 study is limited to 30 seconds, <=4fps and 320–1280px width. Feature masks and dense masks exclude the image's lower region to reduce people/reflection contamination; this intentionally leaves the floor and crowded areas unobserved. Inspect the chosen top fraction and camera path before interpreting the mesh. Per-stage actual commands/API calls, return codes, times and source hash are saved. Quality failure retains evidence and stops instead of fabricating a mesh. Mesh holes are not automatically filled. Local PTS in a downloaded section may differ from original video timestamps because of keyframe seek.
