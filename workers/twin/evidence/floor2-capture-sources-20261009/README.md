## 파일과 근거 범위

`source-controls.json`은 직접 확인한 관계와 확인되지 않은 추론을 구분한다. `guide-crop-manifest.json`은 원본의 픽셀 범위와 SHA를 기록하며, 왜곡 보정이나 요소 추가를 하지 않았다. 새 원본의 취득 기록은 `asset-library/research-public/2026-10-09/floor2-guide-passages/receipts.json`, 재사용 영상 프레임 기록은 `reused-platform-frames/receipts.json`, 무결성 검사 결과는 `source-integrity-qa.json`에 있다.

안내도와 공개 사진은 `reference_only`다. 도식이나 사진의 상대 위치를 현장 실측 정확도로 승격하지 않는다. 최근 크리스피크림 사진이 안내도의 7번과 20번 중 어느 점포인지 확인되지 않았다. ‘1–11 타는 곳’ 유리문 사진도 중앙 26번 입구라고 단정하지 않는다. 작성자가 AI로 만든 출발 전광판 018, 표지 이미지 000, 빈 종료 프레임은 기하 근거에서 제외했다.
