## 남은 한계와 제외

20번 크리스피크림은 실제 전면 사진을 찾았지만 주변 점포·주출입구가 함께 보이는 위치 근거를 확보하지 못했다. 2025년 rano-001 넓은 사진은 큰 LED판 아래 중앙 맞이방 매장을 보여 준다. 2026년 2월 phdite 후기는 “부산역 입구랑은 멀지만 기차타는 곳이랑은 가까워서”라고 설명한다. 이 자료를 20번에 대응하면 기존 7번과 혼동할 수 있다. 전 점포 교체를 뜻하는 검색, 두 크리스피 매장, 입구 왼쪽, 최신 출입구의 표적 검색과 마지막 7월·2022년 사진 검토에서도 20번 주변 위치가 확인되지 않아 `insufficient`로 남겼다. 20번 간판을 다른 매장 사진으로 제작하지 않았다.

11개 시설의 원본 개체 대응은 구조 작업자의 추가 대조가 필요하다. 이번 추가 수집에서 특정 승강장 하행 입구의 새 연속 영상은 확보하지 않았다. 기존 승강장 영상·사진 자료를 그대로 유지한다.

Google AI 개요, 매장 목록, 위치만 적힌 운영자 페이지는 검색 경로로만 사용했다. 사진 원문에 AI 생성 표시를 확인한 자료는 선정하지 않았다. 사진의 실제 촬영 진위는 독립 감식으로 인증하지 않았다. miliyam의 006–011 사진은 오송역이므로 부산역 구조에서 제외한다. amlee의 1층 점포 사진은 2층 구조에서 제외한다. 2014년 유부주머니와 2022년 크리스피 사진은 현재 형상 검증에서 제외한다. 동일 SHA 사진은 독립 증거로 세지 않는다.

첫 Tistory 다운로드는 서명 질의문을 제거해 HTTP 403이 발생했으며 전체 원본 DOM URL로 재수집해 해결했다. merry-001 한 사진은 HTTP 404로 남았고, 나머지 실제 크리스피 사진으로 검토했다. 실패 시도도 영수증에 남겼다. Unity·Assets·씬·공용 문서·설정은 이 수집 작업에서 수정하지 않았다.
