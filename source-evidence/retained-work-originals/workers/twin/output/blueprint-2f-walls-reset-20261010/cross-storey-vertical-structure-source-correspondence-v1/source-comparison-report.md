# 원본 1F·2F 수직 구조 대응 검토

보유 원본을 직접 비교한 유한 목록이다. 앞쪽 두 소형 승강기 샤프트 코어와 내부 기둥 세 곳의 **도면상 배치·격자 순서**를 확인했다. W3-D3의 분리된 표기는 동일한 단일 기둥 축인지 불명확해 학습·검증에서 제외했다. 계단의 층별 발판·참·개구 모서리는 같은 점으로 인정하지 않았다.

이 자료는 원본 도면 사이의 대응 근거다. 1F 월드 변환을 계산하거나 확정하지 않았다. 새로 허용된 LINKED1F 추정은 담당자가 이 자료와 별도로 승인된 2F 원본 기준을 연결해 수행할 수 있으나, 직접 native1F 정합과 구분해야 한다. 원본 native 기둥이 층간에 이어져도 기울거나 굵기가 달라질 수 있다.

## 깊이와 독립 검증

서측 시설 우측 기둥선 W0, 첫째·둘째·셋째 독립 격자 W1·W2·W3, 동쪽 열 번째 간격 E10을 원본에서 세었다. D2는 서측 시설 상단 기둥을 지나는 행, D3는 그 북쪽 한 행, D4는 북쪽 두 행이다. 이 명칭은 원본 비교용이며 native 오브젝트의 신원을 증명하지 않는다.

담당자의 수정된 사전 배정은 TRAIN `W1D2 + E10D2 + 전체 CORE-SW`, HOLD `전체 CORE-SE + C-W2-D2`다. 동일 코어의 네 모서리나 두 샤프트를 독립 검증점으로 부풀리지 않는다. 이 자료는 배정을 기록할 뿐, 추정 행렬이나 정확도를 승인하지 않는다. W3-D3, W1-D4, 미확인 계단은 계산을 성립시키기 위해 강제로 추가하지 않는다.

## 후면 계단 유한 조회

추가 요청에 따라 1F의 후면 세 발판을 확인했다. 원본 ROI는 W `[205,30,255,58]`, C `[440,50,495,78]`, E `[760,50,810,78]`이다. 2F 전체 원본 및 후면 문맥 `[60,255,620,335]`을 비교했으나 동일 flight·참·끝점을 고유하게 식별하지 못했다. native X/Z, 기존 변환에 투영한 근접성, 외부 절단 모서리로 맞추지 않았다. 해당 조회는 여기서 마감한다.

## 검토 이미지와 검증

아홉 장의 `*-source-shape-overlap.png`는 좌측 1F, 가운데 2F, 우측 청록·자홍 윤곽 비교다. 각 도형을 **독립적으로 확대·가운데 배치**했다. 평면 전체 정합, 크기 일치, 거리 정확도 또는 월드 축 비교를 뜻하지 않는다. 원본 픽셀은 변형하지 않은 정수배 최근접 확대 크롭에서 별도로 확인했다.

32개 원본 크롭의 픽셀 일치를 다시 검사했고, 9개 비교 이미지를 직접 확인했다. 새 웹 수집·사진 구조 추론·Unity 호출·Assets 변경·BP1F 복원은 0건이다. 새 2018년 벡터 1F 자료는 후속 담당자에게 전달된 별도 자료이며 이 목록의 근거에 혼합하지 않았다.
