# Coastal Busan WorldSet

Nine deterministic, authored static models generated by `art/blender/build_world_set.py` in Blender4.5.9LTS. Jev019/root supply constrained palette, light and batching choices; Astra low authors and executes the geometric operations. This is a visual RTS kit, not surveyed architecture or accepted production quality.

`art/blender/world-set-manifest.json` records meter dimensions, ground-relative bounds, material names/textures, triangle/mesh counts and approximation limits. FBX export uses Blender `axis_forward=-Z, axis_up=Y`; consumers must observe imported Unity bounds before fitting source geography. Ground pivots are centered in the authored planar footprint. Contact previews use separate presentation scales and are not equal-scale comparisons.

Tower120m height is supported by the Busan city park page. The Jagalchi151×48m envelope, six levels and way382696296 come from root's OSM identification; roof/façade details are approximations. Detailed terminal proportions remain unverified. No reference photographs are redistributed as textures. Existing ambientCG Concrete031/Metal032 CC0 maps are copied under Textures, with source channels recorded per material. Hangul sign geometry uses the existing NotoSansCJKkr font.

Tree placement is not part of this kit. World integration must restrict trees to the source-grounded parks/public spaces and avoid roads/buildings/water. Successful export does not establish visual acceptance, Unity material compatibility or city-wide physical accuracy.
